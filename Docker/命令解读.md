```bash
docker run -d \
--name mysql \
-p 3306:3306 \
-e TZ=Asia/Shanghai \
-e MYSQL_ROOT_PASSWORD=123 \
mysql
```

### 参数解读文本

- `docker run`：创建并运行一个容器，`-d` 是让容器在后台运行
- `--name mysql`：给容器起个名字，必须唯一（便于区分不同的容器）
- `-p 3306:3306`：设置端口映射 前一个：主机里的端口  后一个：容器中的端口  （容器有自己单独的端口）
- `-e KEY=VALUE`：是设置环境变量
- `mysql`：指定运行的镜像的名字

# 二、镜像命名规范

- 镜像名称一般分两部分组成：`[repository]:[tag]`。
    
    - 其中 repository 就是镜像名
    - tag 是镜像的版本
    
- 在没有指定 tag 时，默认是 latest，代表最新版本的镜像

示例：`mysql:5.7`

- mysql → Repository（镜像名）
- 5.7 → Tag（版本标签）
