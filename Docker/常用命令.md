# 图中所有 Docker 命令详细解析

我们按照操作对象分成**镜像相关命令**、**容器相关命令**两大模块逐一讲解，贴合流程图的流转逻辑：

## 一、镜像维度的命令（操作对象是本地镜像）

### 1. 和远端镜像仓库交互

1. `docker pull`
    
    - 作用：**从远程镜像仓库（比如 Docker Hub）下载镜像到本地**
    - 示例：`docker pull nginx`，就是拉取官方的 nginx 镜像存到本机本地镜像库
    
2. `docker push`
    
    - 作用：**把自己本地制作好的镜像上传推送至远端镜像仓库**，方便别处复用这个镜像
    - 示例：`docker push myname/nginx:v1`，推送自制镜像到自己的仓库空间
    

### 2. 通过 Dockerfile 构建镜像

`docker build`

- 作用：读取目录里的`Dockerfile`配置文件，依照文件内的指令一步步打包生成出新的本地镜像
- 常用示例：`docker build -t mydemo:1.0 .`，`.`代表 Dockerfile 所在当前目录，`-t`用来给新镜像设置名字和版本标签

### 3. 镜像本地查看、删除

1. `docker images`
    
    - 作用：罗列本机所有本地镜像，展示镜像 ID、版本标签、体积、创建时间这些信息
    
2. `docker rmi`
    
    - 作用：**删除本地镜像**（末尾 i 代表 image）
    - 示例：`docker rmi nginx` 或者传入镜像 ID 进行删除；注意：镜像已经生成容器时，需要先删掉容器才可以删除镜像
    

### 4. 镜像本地导出 / 导入（离线迁移镜像）

1. `docker save`
    
    - 作用：把本地镜像打包成`.tar`压缩文件，离线拷贝迁移镜像使用
    - 例：`docker save -o nginx.tar nginx`
    
2. `docker load`
    
    - 作用：把`save`导出的 tar 压缩包重新导入恢复成本地镜像
    - 例：`docker load -i nginx.tar`
    

## 二、容器维度的命令（操作对象是由镜像启动出来的容器实例）

### 1. 镜像启动容器

`docker run`

- 核心高频命令：基于本地的某一个镜像，创建出新容器并且启动容器
- 常用参数拓展：
    
    - `-d`：后台静默运行容器；`-p 主机端口:容器端口`：做端口映射；`--name xxx`自定义容器名称
    - 示例：`docker run -d -p 80:80 nginx`
    

### 2. 容器启停状态切换

1. `docker stop`
    
    - 针对**处于运行中**的容器，优雅停止容器，让容器切换到「已停止」状态
    
2. `docker start`
    
    - 将已经停止的容器再次启动，让容器回到运行状态
    

### 3. 查看容器列表

`docker ps`

- 不加参数：仅列出当下正在运行的容器；
- `docker ps -a`：查看本机所有容器，包括已经停止的容器

### 4. 删除容器

`docker rm`

- 删除已经停止的容器；想要删除正在运行的容器需要加上`-f`强制参数
- 区分易错点：`rmi`删镜像、`rm`删容器，二者不要混淆

### 5. 进入容器、查看容器日志

1. `docker logs`
    
    - 查看容器运行输出的日志，排查容器报错、观察程序运行情况非常常用
    - `docker logs -f 容器id`可以持续实时跟踪日志输出
    
2. `docker exec`
    
    - 在**运行状态**的容器内部执行命令，最常用场景是进入容器终端操作
    - 示例：`docker exec -it 容器id /bin/bash`，交互式进入 Linux 容器内部 shell 进行操作
    

## 三、流程图流程梳理帮助整体理解

1. 镜像来源两种方式：要么`pull`远程仓库、要么本地`Dockerfile`执行`build`构建；镜像可以`save/load`离线搬运、`push`上传远端；本地用`images`查镜像、`rmi`删镜像
2. 镜像通过`run`才能实例化为容器；容器可以 stop 停掉、start 重启；ps 查看容器清单、rm 移除容器；运行容器可以 exec 进去操作、logs 看运行日志

## 易混点小结

表格

|命令|操作目标|
|---|---|
|docker rmi|删除**镜像**|
|docker rm|删除**容器**|
|docker pull/push|对接远程仓库|
|docker save/load|本地 tar 包离线迁移镜像|
