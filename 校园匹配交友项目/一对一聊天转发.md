### 🎯 第一步：先理清「一对一聊天」的核心逻辑

现在你的代码里，客户端发消息，服务器只会把消息**回显给发送者自己**。要实现 A 发给 B，需要做这几件事：

1. **消息格式约定**：让客户端发的消息里带上「目标用户学号」，比如：
    
    plaintext
    
    ```
    @2026002:你好呀！
    ```
    
    这样服务器就能解析出：**发送者 A → 目标用户 B → 消息内容**
    
2. **服务器解析消息**：
    
    - 从消息里提取出目标学号（比如`2026002`）
    - 遍历`user_list`，找到这个学号对应的`fd`（客户端连接）
    - 如果找到，就把消息转发给这个`fd`；如果没找到，就告诉发送者「用户不存在」
    
3. **线程安全**：遍历`user_list`时要加互斥锁，防止用户上下线导致列表变化。

### 🧱 第二步：代码改造（核心实现）

#### 1. 先在`handle_client`函数里，解析消息格式

在你读取消息的`while(1)`循环里，加上解析逻辑：

cpp

运行

```
n = read(cfd, buf, sizeof(buf));
if (n <= 0) {
    // ... 原来的下线处理逻辑
} else {
    // 1. 判断是否是一对一消息（以@开头）
    if (buf[0] == '@') {
        // 格式: @目标学号:消息内容
        char target_id[20] = {0};
        char msg_content[1024] = {0};
        
        // 2. 解析目标学号和消息内容
        sscanf(buf, "@%[^:]:%[^\n]", target_id, msg_content);
        
        // 3. 加锁遍历在线用户列表，找到目标用户
        pthread_mutex_lock(&mutex);
        int target_fd = -1;
        for (int i = 0; i < user_count; i++) {
            if (strcmp(user_list[i].id, target_id) == 0) {
                target_fd = user_list[i].fd;
                break;
            }
        }
        pthread_mutex_unlock(&mutex);
        
        // 4. 转发消息
        if (target_fd != -1) {
            // 构造转发消息：[发送者学号] 说: 内容
            char send_buf[1024];
            snprintf(send_buf, sizeof(send_buf), "[%s] 说: %s\n", user_id, msg_content);
            write(target_fd, send_buf, strlen(send_buf));
        } else {
            // 目标用户不在线，回复发送者
            char err_msg[] = "目标用户不在线或不存在！\n";
            write(cfd, err_msg, strlen(err_msg));
        }
    } else {
        // 普通消息：还是回显给自己（保持原来逻辑）
        write(cfd, buf, n);
    }
}
```

#### 2. 关键说明

- `user_id`：就是当前线程服务的用户学号，你在登录时已经存好了
- `sscanf(buf, "@%[^:]:%[^\n]", target_id, msg_content)`：这行是**字符串解析魔法**，专门用来拆分`@学号:消息`这种格式
- 加锁：遍历`user_list`必须加锁，否则多个用户同时上下线会导致数据错乱
