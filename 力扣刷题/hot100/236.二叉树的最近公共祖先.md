[236. 二叉树的最近公共祖先 - 力扣（LeetCode）](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/?envType=problem-list-v2&envId=2cktkvj)

### 解题思路

1. **终止条件**：
    
    - 如果当前节点 `root` 为空，说明已经遍历到叶子节点之外，返回 `NULL`。
    - 如果当前节点 `root` 就是 `p` 或 `q`，那么它本身就是最近公共祖先的候选，直接返回 `root`。
    
2. **递归搜索**：
    
    - 递归地在左子树中查找 `p` 和 `q`，得到结果 `left`。
    - 递归地在右子树中查找 `p` 和 `q`，得到结果 `right`。
    
3. **判断结果**：
    
    - 如果 `left` 和 `right` 都不为空，说明 `p` 和 `q` 分别在当前节点的左右子树中，那么当前节点就是它们的最近公共祖先。
    - 如果 `left` 不为空，`right` 为空，说明 `p` 和 `q` 都在左子树中，最近公共祖先就是 `left`。
    - 如果 `right` 不为空，`left` 为空，说明 `p` 和 `q` 都在右子树中，最近公共祖先就是 `right`。

### C++ 代码实现（带详细注释）

cpp

运行

```
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 递归终止条件：如果当前节点为空，或者当前节点就是p或q，直接返回
        if (root == NULL || root == p || root == q) {
            return root;
        }
        
        // 递归查找左子树
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        // 递归查找右子树
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        
        // 如果左右子树都找到了p或q，说明当前节点就是LCA
        if (left != NULL && right != NULL) {
            return root;
        }
        // 如果左子树找到了，说明p和q都在左子树，返回左子树的结果
        else if (left != NULL) {
            return left;
        }
        // 否则，p和q都在右子树，返回右子树的结果
        else {
            return right;
        }
    }
};
```

---

### 代码解释

- **终止条件**：当我们遇到 `p` 或 `q` 时，就直接返回这个节点，因为它是我们要找的节点之一。
- **递归搜索**：我们分别在左右子树中寻找 `p` 和 `q`。
- **结果判断**：
    
    - 如果左右子树都返回了非空值，说明 `p` 和 `q` 分别在左右子树，当前节点就是它们的最近公共祖先。
    - 如果只有一侧返回了非空值，说明 `p` 和 `q` 都在这一侧，那么这一侧的返回值就是最近公共祖先。

#### 第四步：回到根节点 3

- 左子树返回了 5，右子树返回了 1，两者都不为空。
