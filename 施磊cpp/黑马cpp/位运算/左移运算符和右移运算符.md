### 
- 左移运算，指将一个二进制数向左移动指定位数，左边（高位端）溢出的位被丢弃，右边（低位端）的空位用 0 补充
- 当数值不存在溢出风险时，左移运算的效果相当于原数值乘以 2 的幂
```
#include <iostream>
using namespace std;

int main(){
    int a = 0x40,b;
    b = a << 1;
    cout << b << endl;
    return 0;
}
```


### 右移运算符
- 当数值不存在溢出风险时，右移位运算的效果相当于原数值除以 2 的幂
