# C++ 泛型指针（void*）超简笔记

## 1. 是什么

**泛型指针 = void***

可以指向**任意类型**数据的指针（int、double、结构体、对象都能存）。

## 2. 核心作用

- 通用存储地址
- 通用传参（系统 API、线程、回调）
- 操作原始内存

## 3. 定义写法

cpp

运行

```
int a = 10;
void* p = &a;   // 任意类型地址都能赋值给 void*
```

## 4. 不能直接做的事

- ❌ 不能 `*p` 解引用
- ❌ 不能 `p++` 指针运算
- 原因：编译器**不知道类型和大小**

## 5. 正确使用：强制类型转换（必背）

### C++ 风格（推荐）

cpp

运行

```
// 把 void* 转回 int*
int* real_ptr = static_cast<int*>(p);

// 取值
int value = *real_ptr;
```

### 一行简写

cpp

运行

```
int value = *(static_cast<int*>(p));
```

### C 风格（简单但不安全）

cpp

运行

```
int value = *((int*)p);
```

## 6. 完整示例（可直接运行）

cpp

运行

```
#include <iostream>
using namespace std;

int main() {
    int a = 99;
    double b = 3.14;

    // 泛型指针指向 int
    void* p1 = &a;
    // 转回 int* 并取值
    int val1 = *(static_cast<int*>(p1));
    cout << val1 << endl;

    // 泛型指针指向 double
    void* p2 = &b;
    double val2 = *(static_cast<double*>(p2));
    cout << val2 << endl;

    return 0;
}
```

## 7. 一句话口诀

*_void_ 万能存地址，要用必须转回原类型。**
