### lvalue(左值表达式)
- 判断方法：能够获得这个表达式的引用或者取地址‘
- 在下面的图片中：能获得a的引用，因此a为lvalue；能获得c的地址，因此c为lvalue；不能取到4的地址，因此4不为lvalue
![[Pasted image 20260220224605.png]]

- 下图：refNumber()也是lvalue。当一个函数返回**左值引用**（`T&`）时，调用该函数的表达式 `refNumber()` 就被归类为一个**左值**。
![[Pasted image 20260220225324.png]]


### prvalue 纯右值
```cpp
x = 2;          // 2 是 prvalue
x = m + n;      // m + n 的结果是 prvalue
y = -m;         // -m 的结果是 prvalue
z = n + 2;      // n + 2 的结果是 prvalue
d = (double)z;  // (double)z 的类型转换结果是 prvalue
```

- 下图中：`obj=S{}` 和`obj=S()` 的作用一样，`S{}` 是临时对象，为纯右值。而func();也为prvalue，因为他的返回值为`S{}`，是一个临时对象。
