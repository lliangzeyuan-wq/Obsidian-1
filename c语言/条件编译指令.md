```
#ifdef HELLO
#define HI 20
#endif
```

- **`#ifdef HELLO`**：判断宏 `HELLO` 是否被定义过。
    
    - 如果 `HELLO` 已经被定义（比如在编译时用 `-DHELLO` 参数，或者在其他地方 `#define HELLO`），就会执行下面的 `#define HI 20`。
    - 如果 `HELLO` 没被定义，这一段代码会被编译器直接忽略，`HI` 就不会被定义。
    
- **`#define HI 20`**：定义一个宏 `HI`，让它的值等于 `20`。
    
- **`#endif`**：结束 `#ifdef` 这个条件判断块。
    

---

### 🧩 这段代码的作用

它的逻辑是：

> 只有当 `HELLO` 这个宏被提前定义时，才会把 `HI` 定义为 20；否则 `HI` 就不存在。

所以在第 14 行 `printf("-----------%d\n", HI);` 里：

- 如果编译时加了 `-DHELLO` 参数（比如 `gcc hello.c -DHELLO`），`HI` 就是 20，会正常输出 `-----------20`。
- 如果没定义 `HELLO`，编译器会报 `‘HI’ undeclared` 错误，因为 `HI` 根本没被创建。

---

### 💡 常见用法场景

条件编译主要用在：

1. **功能开关**：比如调试版和发布版用不同代码。
2. **平台兼容**：Windows 和 Linux 下执行不同逻辑。
3. **防止重复包含**：配合 `#ifndef` 避免头文件重复引入。

### ✅ 举个完整例子

如果你想让 `HI` 生效，有两种方式：

**方式 1：在代码里定义 `HELLO`**

c

运行

```
#define HELLO  // 提前定义
#include "hello.h"

int main(...) { ... }
```

**方式 2：编译时传参数定义**

bash

运行

```
gcc hello.c -DHELLO -o hello
```
