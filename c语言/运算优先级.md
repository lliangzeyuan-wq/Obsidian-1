1. **最高优先级：逻辑非 `!`**
    
    `!0` → 结果为 `1`（0 的逻辑非是真，在 C 语言中用 1 表示）。
2. **算术运算：减法 `-`**
    
    `5 - !0` → `5 - 1 = 4`。
3. **关系运算：`>` 和 `<`**
    - `4 > 3` → 真，值为 `1`
    - `7 < 4` → 假，值为 `0`
4. **逻辑与 `&&`**
    
    `1 && 0` → 只要有一个为假，结果为 `0`
