`strlen` 是 C 语言里最常用的**字符串函数**，全称是 **string length**，作用非常简单：**计算字符串的有效长度（不包含结束符 `\0`）**。

我们结合你代码里的这行 `write(sock, message, strlen(message));` 讲透它的作用。

---

### 1. 核心作用

c

运行

```
size_t strlen(const char *str);
```

- ==**功能**：统计字符串 `str` 里从第一个字符开始，到 `\0`（结束符）之前的字符个数。==
- ==**注意**：它**不统计** `\0` 这个结束符。==

---

### 2. 回到你代码里的关键行

c

运行

```
write(sock, message, strlen(message));
```

这里的 `strlen(message)` 就是告诉 `write` 函数：**“我要发送的数据长度是多少。”**

#### 为什么必须这么做？而不是发 `BUF_SIZE`？

因为 `message` 是一个固定大小的数组（比如 1024 字节），但用户实际输入的内容通常很短。

**举个例子：**

1. 用户输入：`hello` + 回车
2. `message` 里存的是：`h e l l o \n ...`
3. `strlen(message)` 的结果是：**5**（只算 `h` 到 `\n` 的长度）。

如果用 `sizeof(message)`（1024）去发送，你会把数组里所有的空字节（垃圾值）都发给服务器了；而用 `strlen`，就能精准地只发送**用户真正输入的那几个字符**。

---

### 3. 结合 `fgets` 的特性（重点！）

你前面用的是 `fgets(message, BUF_SIZE, stdin);`，它有个特殊行为：**会把用户按下的回车符 `\n` 也存进数组里**。

所以执行流程是：

1. 用户输入 `abc` 并回车。
2. `fgets` 读取到 `message`，内容是 `a b c \n \0`。
3. `strlen(message)` 计算出长度是 **4**（3 个字母 + 1 个换行符）。
4. `write` 发送 4 个字节，服务器就能收到 `abc` 加上一个换行，完美还原输入效果。

---

### 4. 对比一下错误写法

表格

|写法|效果|结果|
|:--|:--|:--|
|**`strlen(message)`**|发送用户输入的**实际内容**（含换行）|正常收发，回声正确|
|**`sizeof(message)`**|发送整个数组（1024 字节）|会发送大量乱码 / 空字节，服务器接收混乱|
|**`strlen(message)-1`**|去掉换行符发送|发出去的内容没有换行，回声也不换行，体验不好|

### 总结

`strlen(message)` 就是为了**精准控制发送的字节数**，保证只把用户输入的那一行数据（包含换行）原封不动发给服务器。

它是网络编程里发送字符串的标准写法。
