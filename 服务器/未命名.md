### 关键检查项（如果访问不了，优先排查这两点）

1. **阿里云防火墙必须放行端口**
    
    去阿里云控制台，确认已经添加了这两条安全组规则：
    
    - 协议：`TCP`，端口：`8080`（后端接口）
    - 协议：`TCP`，端口：`3001`（前端网页）
        
        来源选择`0.0.0.0/0`，允许所有 IP 访问。
    
2. **查看日志排查异常**
    
    如果访问报错或功能异常，可以查看日志定位问题：
    
    - 后端日志：`cat ~/server.log`
    - 前端日志：`cat ~/campus-social-frontend/frontend.log`

### 💡 后续维护小技巧

服务器重启后，后台进程会被关闭，每次都要手动执行启动命令。可以把两个命令写成一键启动脚本：

1. 新建脚本文件：
    
    bash
    
    运行
    
    ```
    nano start.sh
    ```
    
2. 写入以下内容：
    
    bash
    
    运行
    
    ```
    #!/bin/bash
    # 启动后端服务
    cd ~ && nohup ./server > server.log 2>&1 &
    # 启动前端服务
    cd ~/campus-social-frontend && nohup python3 -m http.server 3001 > frontend.log 2>&1 &
    echo "前后端服务已启动！"
    ```
    
3. 给脚本执行权限：
    
    bash
    
    运行
    
    ```
    chmod +x start.sh
    ```
    
4. 下次直接一键启动：
    
    bash
    
    运行
    
    ```
    ./start.sh
    ```
