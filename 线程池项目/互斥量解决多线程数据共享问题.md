- 线程安全：当你的多线程程序每一次运行结果和单线程运行的结果始终是一样的，那么你的线程就是安全的


- 错误代码
```cpp
#include<iostream>
#include<thread>
int a = 0;
void func() {
	for (int i = 0; i < 10000; i++)
	{
		a += 1;
	}
}
int main() {
	std::thread t1(func);
	std::thread t2(func);
	
	t1.join();
	t2.join();
	
	std::cout << a << std::endl;
	return 0;
}
```
- 错误的原因：当两个进程同时进行的时候，本来应该加2的，但实际上只加了1（因为是同时进行的）


**正确代码**
- 加上互斥锁
- lock()上锁，此时不允许其他进程运行，结束点为unlock开锁
```cpp
#include<iostream>
#include<thread>
#include<mutex>
int a = 0;
std::mutex mtx;
void func() {
	for (int i = 0; i < 10000; i++)
	{
		mtx.lock();
		a += 1;
		mtx.unlock();
	}
}
int main() {
	std::thread t1(func);
	std::thread t2(func);
	
	t1.join();
	t2.join();
	
	std::cout << a << std::endl;
	return 0;
}

```
