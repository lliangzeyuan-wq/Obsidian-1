- 为什么需要线程池？
	- 1.**耗时任务异步抛到其他线程执行，解放核心线程的处理能力**
		在后端服务中，比如一个 Web 服务器，**核心线程**负责接收用户的 HTTP 请求并快速响应。如果核心线程去处理一个耗时很长的任务（比如文件 IO、数据库查询、复杂计算），它就会被阻塞，无法处理新的请求，导致服务响应变慢甚至超时。所以，我们会把这些耗时任务**异步提交**给线程池，让其他线程去做。这样核心线程就能立刻腾出手来，处理下一个用户的请求，保证了服务的吞吐量和响应速度。
	- 2.**更大限度利用系统资源**
		如果没有线程池，我们手动创建线程，很容易出现两种极端情况： - **线程太少**：CPU 和内存等资源大部分时间都在空闲，没有被充分利用。- **线程太多**：操作系统需要花费大量时间进行线程上下文切换，反而降低了整体效率，甚至导致系统崩溃。              线程池通过**合理配置核心线程数、最大线程数、队列长度**等参数，可以让 CPU 始终保持在一个较高的利用率水平，同时又不会因为线程过多而产生过多的切换开销，从而最大化地利用系统资源。
