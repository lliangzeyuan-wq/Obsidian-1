- 在c++中，当使用std::thread创建线程并传递类成员函数是，需要使用&来获取成员函数的地址，同时还需要传递对象的指针（或引用）作为作为第一个参数

### 如何在thread中使用引用
```cpp
#include<iostream>
#include<thread>
void foo(int& x) {
	x += 1;
}
int main() {
	int a = 1;
	std::thread t(foo, std::ref(a));
	std::cout << a << std::endl;
	t.join();
	std::cout << a << std::endl;

	return 0;
}
```

你必须使用std::ref(a); 因为thread默认是按值引用的
