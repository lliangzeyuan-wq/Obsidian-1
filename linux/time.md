
### ⏱ time 命令（可直接复制）

**作用**：测程序 / 命令跑多久、耗多少 CPU，不是改系统时间（改时间用 `date`）。

### 1. 用法（直接复制）

bash

运行

```
# 格式
time 你要跑的命令或程序

# 示例1：测 ls
time ls

```

### 2. 输出含义（必懂）

plaintext

```
real    0m1.002s   # 实际墙上时间（从开始到结束，含等待）
user    0m0.980s   # 用户态 CPU 时间（程序代码本身）
sys     0m0.020s   # 内核态 CPU 时间（系统调用/内核干活）
```

- **real ≈ 1s**：和 `alarm(1)` 一致，1 秒左右退出。
- **user+sys**：CPU 真正干活的时间，**远小于 real** 说明卡在 I/O（比如频繁 printf）。
