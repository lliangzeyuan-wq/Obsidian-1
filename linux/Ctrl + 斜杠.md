# Ctrl + \


一句话：**Ctrl+\ 是 “强制退出 + 生成 core”**，比 Ctrl+C 更狠，用于**杀不掉、卡死、需要调试**的情况。

### 一、它发什么信号？

- **Ctrl+\ → SIGQUIT（信号 3）**
- 默认动作：**终止进程 + 生成 core 转储文件**（程序崩溃时的内存快照）

### 二、和 Ctrl+C / Ctrl+Z 对比（必背）

表格

|按键|信号|作用|是否可恢复|
|---|---|---|---|
|**Ctrl+C**|SIGINT(2)|正常终止（温柔杀）|否|
|**Ctrl+Z**|SIGTSTP(20)|暂停、挂起|是（fg/bg）|
|*_Ctrl+*_|SIGQUIT(3)|强制退出 + core 文件|否|

简单记：

- **Ctrl+C** = 礼貌请你走
- **Ctrl+Z** = 先歇着，等我叫你
- *_Ctrl+*_ = 立刻滚，留下 “遗言”（core）

### 三、什么时候用 Ctrl+\？

1. **Ctrl+C 杀不掉程序**（卡死、死循环、忽略 SIGINT）
2. **程序崩溃 / 卡死，需要调试**：core 文件可用来 gdb 分析原因
3. **彻底退出，不想保留状态**

### 四、core 文件是什么？

- 程序意外退出时，系统生成的 **内存镜像文件**
- 文件名：**core** 或 **core.PID**
- 用途：用 gdb 调试，定位崩溃原因（比如段错误）

### 五、实操例子

bash

运行

```
# 跑一个死循环程序
while :; do :; done

# 按 Ctrl+C → 可能杀不掉（有的程序忽略）
# 按 Ctrl+\ → 直接退出，并提示：
# Quit (core dumped)
# 目录下多了 core 文件
```

### 六、补充：怎么关掉 core（有时候很烦）

临时关闭：

bash

运行

```
ulimit -c 0
```

### 七、总结（超简版）

- **Ctrl+\ = SIGQUIT = 强制退出 + core dump**
- 比 Ctrl+C 强，比 kill -9 弱（还能留调试信息）
- 日常少用，**卡死 / 调试**才用
