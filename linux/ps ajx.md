

## 一、命令整体作用

`ps ajx` 是 Linux 系统中一个**非常常用的进程查看命令**，它的核心特点是：

- **显示所有进程**（包括守护进程、后台进程）
- **完整显示父子进程关系**（PPID）
- **BSD 风格的输出格式**，信息更全

---

## 二、参数拆解（BSD 风格）

`ps` 命令有两种主流用法风格：System V（比如 `ps aux`）和 BSD（比如 `ps ajx`）。

`ps ajx` 是**BSD 风格**的写法，参数不需要加 `-`：

表格

|参数|全称|作用|
|:--|:--|:--|
|`a`|all|显示**所有用户**的进程，包括其他用户和无终端的进程|
|`j`|jobs|以**作业控制格式**输出，会额外显示 `PPID`（父进程 ID）、`PGID`（进程组 ID）、`SID`（会话 ID）等信息|
|`x`|-|显示**没有控制终端**的进程（比如系统守护进程 `systemd`、`cron` 等）|

---

## 三、输出字段详解

执行 `ps ajx` 后，会输出比 `ps aux` 更丰富的信息，典型输出如下：

bash

运行

```
PPID   PID  PGID   SID TTY      TPGID STAT   UID   TIME COMMAND
    0     1     1     1 ?           -1 Ss       0   0:02 /sbin/init
    1  1234  1234  1234 pts/1    1234 Ss    1000   0:00 bash
 1234  5678  5678  1234 pts/1    5678 R+    1000   0:00 ./fork
```

重点字段解释：

- `PPID`：Parent Process ID，**父进程 ID**。这是 `j` 参数带来的关键信息，用来快速查看进程的父子关系，排查僵尸进程时非常有用。
- `PID`：Process ID，进程 ID。
- `PGID`：Process Group ID，进程组 ID。
- `SID`：Session ID，会话 ID。
- `STAT`：进程状态（`S` 休眠、`R` 运行、`Z` 僵尸进程等）。
- `UID`：进程所属用户的 ID。
- `COMMAND`：进程的命令 / 程序名。

---

## 四、和 `ps aux` 的核心区别

表格

|对比项|`ps ajx`|`ps aux`|
|:--|:--|:--|
|**风格**|BSD 风格|System V 风格|
|**关键信息**|自带 `PPID`（父进程 ID），适合分析进程树|自带 `%CPU`/`%MEM`，适合分析资源占用|
|**适用场景**|排查僵尸进程、分析父子进程关系|排查进程 CPU / 内存占用过高问题|

---

## 五、常用搭配

1. **过滤特定进程**
    
    bash
    
    运行
    
    ```
    # 查找 PID 为 5678 的进程
    ps ajx | grep 5678
    
    # 过滤掉 grep 命令本身
    ps ajx | grep 5678 | grep -v grep
    ```
    
2. **分析进程父子关系**
    
    结合 `PPID` 字段，快速找到进程的父进程，比如排查你之前的 `fork` 程序时：
    
    bash
    
    运行
    
    ```
    # 查看 ./fork 进程的父子关系
    ps ajx | grep fork
    ```
    

---

简单来说，`ps ajx` 是**为分析进程关系而生**的命令，尤其适合你现在学习 `fork()`、僵尸进程、进程组这些知识点。
