# 打开文件
```c
#include<sys/types.h>
#include<sys/stat.h>
#include<fcntl.h>

int open(const char *path,int flag);
//成功时返回文件描述符，失败时返回-1
//path：文件名的字符串地址
//flag：文件的打开模式
```
> 文件的打开模式（flag)
> O_CREAT   必要时创建文件 (**O**pen **CREAT**e)
> O_TRUNC  删除全部现有数据 (**O**pen **TRUNC**ate)
> O_APPEND 维持现有数据，保存到其后面 (**O**pen **APPEND**)
> O_RDONLY  只读打开  (**O**pen **R**ead **D**ata **ONLY**)
> O_WRONLY  只写打开 (**O**pen **WR**ite **ONLY**)
> O_RDWR  读写打开 (**O**pen **R**ead **D**ata **WR**ite)

- 当需要使用多个文件打开模式（flag）的时候，用`|` 来连接

# 关闭文件
```c
#include<unistd.h>

int close(int fd);
//成功时返回0，失败时返回-1
//fd：需要关闭的文件或套接字的文件描述符
```

- 此函数不仅可以关闭文件，也可以关闭套接字，再次证明了“Linux不区分文件和套接字”的特点

# 将数据写入文件
```c
#include<unistd.h>

ssize_t write(int fd,const void *buf,size_t nbytes);
//成功时返回写入的字节数，失败时返回-1
//fd：显示数据传输对象的文件描述符
//buf：保存要传输数据的缓冲地址值
//nbytes：要传输数据的字节数
```
- size_t是通过typedef声明的unsigned int类型。 对ssize_t来说， size_t前面多加的s代表signed，即ssize_t是通过typedef声明的signed int类型。

>像size_t ,ssize_t这类带 `_t`  后缀的类型，本质是系统通过typedef给基本数据类型起的别名，定义在 `sys/types.h` 等系统头文件中。
- 为什么要使用这类类型
>基本数据类型（如int）的长度会随操作系统、硬件变化：16位系统中int是2字节，32/64位系统中的int通常是4字节，用size_t/ssize_t 这类起别名，只需要修改系统头文件中的typedef定义，从而大大提升了代码的可移植性。 

# 代码示例
```c
#include<stdio.h>                                           
#include<stdlib.h>                                          
#include<fcntl.h>                                           
#include<unistd.h>                                          
void error_handling(char *message);                         
                                                            
int main(void)                                              
{                                                           
    int fd;                                                 
    char buf[]="Let's go\n";                                
                                                            
    fd=open("data.txt",o_CREAT|O_WRONLY|O_TRUNC);           
    if(fd==-1)                                              
        error_handling("open() error!");                    
    printf("file descriptor:%d\n",fd);                      
    if(write(fd,buf,sizeof(buf))==-1)                      
        error_handling("write() error!");                   
    close(fd);                                              
    return 0;                                               
}                                                           
                                                            
                                                            
                                                            
void error_handling(char *message)                          
{                                                           
    fputs(message,stderr);                                  
    fputc('/n',stderr);                                     
    exit(1);                                                
}                                                           
                                                            

```

# 读取文件中的数据
```cpp
#include<unistd.h>;

ssize_t read(int fd,void * buf, size_t nbytes);
//返回值：成功时是实际读到的字节数，失败时返回-1
//fd:显示数据接受对象的文件描述符
//buf：要保存接受数据的缓冲地址符
//nbytes：要接受数据的最大字节数
```
