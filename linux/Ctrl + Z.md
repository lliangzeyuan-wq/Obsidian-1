# 一句话讲透 **Ctrl + Z**

**Ctrl + Z** = **暂停当前前台进程**，把它挂起、丢到后台，立刻把终端还给你。

我用最简单、最实用的方式给你讲清楚👇

---

## 1. Ctrl + Z 到底做了什么？

当你运行一个程序（比如 `./a.out`、`vim`、`top`），按：

plaintext

```
Ctrl + Z
```

系统会：

1. **暂停**当前前台进程（不是杀死！不是退出！）
2. 把进程丢到**后台**
3. 立刻还给你终端，让你继续输命令

进程状态变成：

plaintext

```
Stopped（暂停）
```

---

## 2. 暂停 vs 退出（超级重要）

- **Ctrl + C**：**杀死进程**，彻底结束
- **Ctrl + Z**：**暂停进程**，进程还在内存里，只是不运行了

---

## 3. 按完 Ctrl + Z 之后能干什么？

你有 3 个选择：

### ① 恢复到前台继续跑（fg）

bash

运行

```
fg
```

程序回到前台，继续运行。

### ② 丢到后台继续跑（bg）

bash

运行

```
bg
```

程序在后台默默运行，不占用终端。

### ③ 查看暂停的任务（jobs）

bash

运行

```
jobs
```

会看到：

plaintext

```
[1]+  Stopped   ./a.out
```

---

## 4. 最常用的一套流程（必背）

bash

运行

```
# 1. 运行程序（前台）
./a.out

# 2. 按 Ctrl+Z 暂停
[1]+ Stopped ./a.out

# 3. 丢后台继续跑
bg

# 4. 想切回来继续看
fg
```

---

## 5. 超级简单的总结

- **Ctrl + C** = 杀死程序
- **Ctrl + Z** = 暂停程序 + 丢后台 + 还你终端
- **fg** = 切回前台
- **bg** = 后台继续跑
