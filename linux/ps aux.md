
我们来拆解一下这个命令：`ps aux | grep 7876`，它是 Linux 里**专门用来根据进程号（PID）查找进程信息**的组合命令。

---

### 一、命令拆分讲解

#### 1. `ps aux`：列出系统中所有进程

- `ps`：是 Process Status 的缩写，用来查看当前系统的进程状态。
- `a`：显示所有用户的进程，包括没有控制终端的进程。
- `u`：以用户友好的格式显示进程信息，包含用户、PID、CPU / 内存占用等字段。
- `x`：显示不依赖终端的进程（比如后台守护进程）。

所以 `ps aux` 会输出一个包含系统中所有进程的大列表，每一行都是一个进程的详细信息，比如：

plaintext

```
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1 168404  9824 ?        Ss   10:00   0:01 /sbin/init
lzy       7876  0.0  0.2 123456 15678 pts/0    S+   10:10   0:00 ./fork
```

#### 2. `|`：管道符

- 它的作用是**把前一个命令的输出，作为后一个命令的输入**。
- 在这里，就是把 `ps aux` 输出的所有进程列表，交给后面的 `grep` 命令处理。

#### 3. `grep 7876`：过滤包含 “7876” 的行

- `grep` 是文本搜索工具，用来从输入中筛选出包含指定模式的行。
- 这里的 `7876` 是进程的 PID（Process ID），`grep 7876` 会在 `ps aux` 的输出里，筛选出所有包含数字 `7876` 的行。

---

### 二、命令整体作用

合起来看，`ps aux | grep 7876` 的作用是：

> 列出系统中所有进程，然后只显示进程号（PID）为 `7876` 的进程信息。

#### 输出示例：

plaintext

```
lzy       7876  0.0  0.2 123456 15678 pts/0    S+   10:10   0:00 ./fork
lzy       7880  0.0  0.0   6000   800 pts/0    S+   10:10   0:00 grep --color=auto 7876
```

- 第一行：就是 PID 为 `7876` 的进程，也就是你用 `fork()` 创建的程序。
- 第二行：是 `grep` 命令本身的进程，它也包含 `7876`，所以也会被筛选出来，这是正常现象。

---

### 三、补充说明

1. **为什么用这个命令？**
    
    当你运行 `fork()` 创建的程序后，想确认进程是否存在、它的状态（运行 / 休眠 / 僵尸）、占用资源等，就可以用这个命令来查看。
    
2. **如何去掉 `grep` 自身的那一行？**
    
    可以加一个过滤条件，排除 `grep` 进程：
    
    bash
    
    运行
    
    ```
    ps aux | grep 7876 | grep -v grep
    ```
    
    这样输出就只剩下你要找的进程了。
    

---

简单来说，这是 Linux 里最常用的 “按 PID 查进程” 的方式，非常实用。
