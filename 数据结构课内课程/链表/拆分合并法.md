# 题目
某非空单链表L中所有元素为整数，设计一个算法将所有小于零的结点移到所有大于等于零的结点的前面。

#### 方法：拆分合并法（保证稳定性，空间 O (1)）

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void moveNegFront(LinkList L) {
    // 1. 初始化两个带头结点的子链表，分别存放负数和非负数
    LNode negHead, nonNegHead;
    LinkList p = L->next;      // 原链表遍历指针
    LinkList q = &negHead;     // 负数链表尾指针
    LinkList r = &nonNegHead;  // 非负数链表尾指针

    // 初始化子链表
    negHead.next = NULL;
    nonNegHead.next = NULL;

    // 2. 遍历原链表，拆分结点
    while (p != NULL) {
        if (p->data < 0) {
            // 负数：接入负数链表
            q->next = p;
            q = q->next;
        } else {
            // 非负数：接入非负数链表
            r->next = p;
            r = r->next;
        }
        p = p->next;
    }

    // 3. 切断表尾，防止环
    r->next = NULL;

    // 4. 合并链表：负数链表 + 非负数链表
    q->next = nonNegHead.next;

    // 5. 结果放回原链表（L->next 指向新表头）
    L->next = negHead.next;
}
```

---

### 算法思路解析

1. **拆分链表**：
    
    - 遍历原链表，把所有**小于 0 的结点**串成一个新链表`negHead`。
    - 把所有**大于等于 0 的结点**串成另一个新链表`nonNegHead`。
    
2. **合并链表**：
    
    - 把 “负数链表” 的尾结点指针指向 “非负数链表” 的头结点。
    
3. **完成重组**：
    
    - 将合并后的链表头（`negHead.next`）挂回原链表的头结点 `L->next` 下。
    

---

### 复杂度分析

- **时间复杂度**：O(n)，仅遍历一次原链表。
- **空间复杂度**：O(1)，仅使用了几个辅助指针，没有新开结点空间。

### 关键注意点

- **一定要断尾**：`r->next = NULL;` 这一步非常重要，否则非负数链表的尾结点可能还指向原来的结点，导致链表出现环或访问非法内存。
- **稳定性**：该算法保留了原链表中负数之间、非负数之间的相对顺序，是一种**稳定**的算法。
