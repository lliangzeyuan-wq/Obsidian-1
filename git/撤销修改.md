# 1. `git reset --hard HEAD`

## 作用

**把 所有已经被 Git 管理的文件，强制恢复到上一次提交的状态。**

## 它会处理这些情况：

- 你修改了某个文件的代码 → **恢复原样**
- 你删除了某个文件 → **恢复回来**
- 你重命名了某个文件 → **恢复原名**

## 它**不会**处理：

- 你**新建**的、从来没提交过的文件 / 文件夹

## 一句话总结

**只管 “老文件”，不管 “新文件”。**

---

# 2. `git clean -fd`

## 作用

**删除所有 新建的、Git 不认识的、未被追踪的文件 / 文件夹。**

## 它会处理：

- 你新建的 `.txt`
- 你新建的 `test.cpp`
- 你新建的文件夹 `images/`
- 任何没被 Git 记录过的新东西

## 一句话总结

**只删 “新文件”，不管 “老文件”。**

---

# 两个命令合在一起 = 终极清空

bash

运行

```
git reset --hard HEAD   # 恢复所有老文件
git clean -fd           # 删除所有新文件
```

执行完这两条：

✅ 所有修改消失

✅ 所有删除恢复

✅ 所有新建文件被删除

✅ 工作区**100% 干净**

---

# 最直观的对比（一看就懂）

表格

|你的操作|git reset --hard HEAD|git clean -fd|
|---|---|---|
|修改老文件|✅ 恢复|❌ 不处理|
|删除老文件|✅ 恢复|❌ 不处理|
|新建文件|❌ 不处理|✅ 删除|
|新建文件夹|❌ 不处理|✅ 删除|
