## 方法一：命令行（最常用、信息最全）

打开 VS Code 的终端，输入以下命令：

1. **查看本地所有分支**
    
    bash
    
    运行
    
    ```
    git branch
    ```
    
    输出结果中，前面带 `*` 号的就是你当前所在的分支。
    
2. **查看本地 + 远程所有分支**（推荐）
    
    bash
    
    运行
    
    ```
    git branch -a
    ```
    
    会同时显示你本地的分支，和 GitHub 远程仓库的所有分支（远程分支通常以 `remotes/origin/` 开头）。
    
3. **查看所有分支 + 最后一次提交信息**
    
    bash
    
    运行
    
    ```
    git branch -av
    ```
    
    除了分支名，还会显示每个分支最后一次提交的 ID 和说明，更直观。
