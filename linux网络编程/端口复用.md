**场景**：服务器没正常关闭（比如按 `Ctrl+C` 强制退出），你马上重启服务器，就会报这个错。

**原因**：

TCP 协议规定，连接关闭后，端口不会立刻释放，会进入一个叫 `TIME_WAIT` 的状态，系统会保留这个端口 **2 分钟左右**，防止旧的网络数据包干扰新连接。

这时候你想重启服务器，系统会说：「这个端口还在被占着，我不能给你用！」

### 2. 端口复用是什么？

**端口复用（`SO_REUSEADDR`）** 就是告诉系统：

> 「这个端口我要马上用，哪怕它还在 `TIME_WAIT` 状态，也允许我重新绑定！」

加了这行代码后，服务器异常退出后，**立刻就能重启**，再也不会报 `Address already in use` 了 ✅



### 函数原型
```
#include <sys/socket.h>

// 函数原型
int setsockopt(int sockfd, 
               int level, 
               int optname, 
               const void *optval, 
               socklen_t optlen);
```

## 三、你只需要记住：端口复用固定写法

**你不用深究所有用法**，开发服务器时，**端口复用就固定这么写**，直接背会：

- 你只需要确定这个sockfd，其他的都是固定写法
```cpp
// 固定代码：开启端口复用
int opt = 1;
setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
```

作用：解决 `Address already in use` 端口占用报错。
