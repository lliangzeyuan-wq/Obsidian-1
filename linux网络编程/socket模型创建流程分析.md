- 客服端服务器一共有3个套接字，客户端一个，服务端的一个用于和客户端的这一个配对，服务端的另一个用于监听

### socket模型创建流程图
![[Pasted image 20260313131223.png]]
- socket()
![[Pasted image 20260313131308.png]]
- bind()   :   往套接字上去绑定ip地址和端口
- listen()  :  设置监听上限（即同时和服务端连接的客户端的数量的最大上限）
- accept()  :   阻塞监听客户端连接     当调用accept的时候，需要用到一个socket作为参数传进来，当accept成功跟客户端建立连接的时候，他会返回一个新的socket，原来的socket就被解放出来了，派他去监听（监听：监听就像酒店迎宾小姐，客户来了，监听领着客户到房间去，到房间去了之后有其他人接待你了，之后监听再去酒店门口去迎接其他人）
