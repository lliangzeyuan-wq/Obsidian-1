## 当计算第二问：恰好满足背包总体积为V的时候
![[Pasted image 20260323160642.png]]- `f[0][1]`:我想要在前0个物品中，让物品的总体积恰好为1
- `f[0][2]`:我想要在前0个物品中，让物品的总体积为2
- `f[0][3]`:我想要在前0个物品中，让物品的总体积为3
- 这显然是不合理，不可能的，这些格子就是不合理的格子
- 如果后面的格子用了这些不合理的格子的话，他们也会变成不合理的格子，那怎么表示这些不合理的格子呢，有两种方法（如下图）
![[Pasted image 20260323162439.png]]
- 这里我们用第二种方法，因为写法比较简单

```cpp
#include<iostream>

using namespace std;

#include<cstring>

const int N=1010;

int w[N],v[N];//v:体积，w：价值

int f[N][N];

int main()

{

    int n,m;

    cin>>n>>m;

    for(int i=1;i<=n;++i)

    {

        cin>>v[i]>>w[i];

    }

    for(int i=1;i<=n;++i)

    {

        for(int j=0;j<=m;++j)

        {

            f[i][j]=f[i-1][j];

            if(j>=v[i])

            {

                f[i][j]=max(f[i][j],f[i-1][j-v[i]]+w[i]);

            }

        }

    }

    cout<<f[n][m]<<endl;

  

    //第二问

    memset(f,-0x3f,sizeof f);

    f[0][0]=0;

     for(int i=1;i<=n;++i)

    {

        for(int j=0;j<=m;++j)

        {

            f[i][j]=f[i-1][j];

            if(j>=v[i])

            {

                f[i][j]=max(f[i][j],f[i-1][j-v[i]]+w[i]);

            }

        }

    }

  
  

    if(f[n][m]<0) cout<<0<<endl;

    else cout<<f[n][m]<<endl;

  
  

    return 0;

}
```
