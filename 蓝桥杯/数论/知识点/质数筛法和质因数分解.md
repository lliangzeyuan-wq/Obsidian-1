## 一、先搞懂基础概念

### 1. 什么是质数 / 合数？

- **质数（素数）**：大于 1 的整数，只能被「1」和「它自己」整除，比如 2、3、5、7、11...
- **合数**：大于 1 的整数，除了 1 和自己，还有其他因数，比如 4=2×2、6=2×3、12=2×2×3...
- 1 既不是质数也不是合数。

### 2. 我们为什么要学「筛质数」？

蓝桥杯很多数论题（比如你做的「因子链」、「等差数列」、「约数计数」），都需要：

- 批量找出某个范围内的所有质数
- 快速把一个数拆成质数相乘（质因数分解）
    
    如果一个个手动试除，效率极低，筛法就是**批量找质数的最快方法**。

---

## 二、先学简单的：埃氏筛（铺垫，理解线性筛的基础）

### 原理

要找 2~n 之间的所有质数：

1. 一开始默认所有数都是质数（标记为「未划掉」）
2. 从最小的质数 2 开始，把 2 的所有倍数（4、6、8、10...）都划掉（这些都是合数）
3. 下一个没被划掉的数是 3，把 3 的所有倍数（6、9、12...）都划掉
4. 再下一个没被划掉的是 5，划掉 5 的倍数...
5. 直到遍历到√n，剩下没被划掉的数就是所有质数

### 缺点

一个合数会被**多个质数重复划掉**，比如 6 会被 2 和 3 各划一次，12 会被 2、3 各划一次，重复操作多，大数据（比如 1e6）效率低，而且**不能记录每个数的最小质因数**，不方便后续分解。

---

## 三、省赛标准写法：线性筛（欧拉筛）—— 核心考点

### 核心原理（一句话）

**让每个合数，只被它的「最小质因数」划一次，彻底避免重复，时间复杂度 O (n)，还能顺便记录每个数的最小质因数！**

### 什么是「最小质因数」？

能整除这个数的**最小的质数**，比如：

- 6 的因数有 2、3，最小的是 2 → 6 的最小质因数是 2
- 12 的因数有 2、3，最小的是 2 → 12 的最小质因数是 2
- 9 的因数有 3 → 9 的最小质因数是 3
- 质数的最小质因数就是它自己（比如 5 的最小质因数是 5）

---

### 代码逐行大白话拆解

cpp

运行

```
const int N = 1e6+10;  // 数组大小：1e6+10，覆盖蓝桥杯省赛绝大多数数据范围
int primes[N], cnt;     // primes[] 存筛出来的所有质数；cnt 是质数的个数
int minp[N];            // minp[i] 存「数字i的最小质因数」
bool st[N];             // st[i] 标记i是否为合数：true=合数，false=质数（初始全为false，默认都是质数）

// 线性筛函数：筛出2~n的所有质数，同时计算minp数组
void get_primes(int n) {
    // 外层循环：从2到n，逐个检查每个数
    for(int i=2; i<=n; i++) {
        // 如果st[i]是false → 没被标记过，说明i是质数！
        if(!st[i]) {
            primes[cnt++] = i;  // 把质数i存入primes数组，计数+1
            minp[i] = i;         // 质数的最小质因数就是它自己
        }

        // 内层循环：用已经筛出来的质数，去筛合数（线性筛核心）
        for(int j=0; primes[j]*i <=n; j++) {
            int t = primes[j] * i;  // 要筛的合数：质数 × 当前数i
            st[t] = true;           // 标记t为合数
            minp[t] = primes[j];    // t的最小质因数就是primes[j]（第一个能整除t的质数）

            // 🔥 核心优化：如果i能被primes[j]整除，直接break！
            if(i % primes[j] == 0) break;
        }
    }
}
```

### 用「筛 2~10」的完整例子，带你走一遍，秒懂！

我们要筛出 2 到 10 的所有质数，同时计算 minp 数组：

表格

|步骤|i 的值|st [i] 状态|操作|内层循环|筛出的合数|minp 更新|break 判断|
|---|---|---|---|---|---|---|---|
|1|i=2|st [2]=false（质数）|把 2 存入 primes，minp [2]=2|j=0，primes[0]=2，t=2×2=4|标记 4 为合数|minp[4]=2|2%2==0 → break|
|2|i=3|st [3]=false（质数）|把 3 存入 primes，minp [3]=3|j=0，primes [0]=2，t=2×3=6 → 标记 6 为合数，minp [6]=2；3%2≠0，继续 j=1，primes [1]=3，t=3×3=9 → 标记 9 为合数，minp [9]=3|6、9|minp[6]=2，minp[9]=3|3%3==0 → break|
|3|i=4|st [4]=true（合数）|不存质数|j=0，primes [0]=2，t=2×4=8 → 标记 8 为合数，minp [8]=2|8|minp[8]=2|4%2==0 → break|
|4|i=5|st [5]=false（质数）|把 5 存入 primes，minp [5]=5|j=0，primes [0]=2，t=2×5=10 → 标记 10 为合数，minp [10]=2；5%2≠0，j=1，primes [1]=3，3×5=15>10 → 循环结束|10|minp[10]=2|无 break|
|5|i=6~10|都是合数（st [i]=true）|不存质数|筛后续合数（都 > 10，循环不执行）|无|无|无|

### 最终结果

- 质数数组 primes：`[2,3,5,7]`（2~10 的所有质数）
- minp 数组：`minp[4]=2, minp[6]=2, minp[8]=2, minp[9]=3, minp[10]=2`
- 每个合数**只被筛了一次**，完全没有重复！

---

### 为什么`if(i%primes[j]==0) break`是核心？

用 i=4 举例子：

- i=4，primes [j]=2，4%2==0 → 直接 break，不乘后面的 3
- 如果不 break，会计算`3×4=12`，把 12 标记为合数，但 12 的最小质因数是 2，12 已经被`2×6`筛过了，再用`3×4`筛就是**重复操作**
- break 的作用：保证每个合数**只被它的最小质因数筛一次**，彻底消除重复，让时间复杂度降到 O (n)，这就是线性筛比埃氏筛快的原因！

## 四、用筛好的 minp 数组，快速做「质因数分解」

### 什么是质因数分解？

把一个合数，拆成**若干个质数相乘**的形式，比如：

- 12 = 2×2×3
- 100 = 2×2×5×5
- 18 = 2×3×3

### 普通方法 vs 线性筛方法

- 普通方法：试除，从 2 开始除到√x，慢，大数据效率低
- 线性筛方法：用 minp 数组，**O (logx) 时间快速分解**，蓝桥杯省赛标准写法

---

### 代码逐行大白话拆解

cpp

运行

```
// 质因数分解x，用minp数组快速分解
void divide(int x) {
    while(x > 1) {  // 只要x还没拆成1，就继续拆
        int p = minp[x];  // 🔥 取x的「最小质因数」p
        // 统计p的指数：一直除以p，直到不能整除
        while(x % p == 0) {
            x /= p;  // x除以p，更新x的值
            // 这里可以加代码统计p的指数，比如sum[k]++（就是你之前因子链里的操作）
        }
        // 处理下一个质因数
    }
}
```

---

### 用「分解 100」的例子，带你走一遍

我们要分解 100，用 minp 数组：

1. x=100>1，minp [100]=2（100 的最小质因数是 2）
    
    - x%2==0 → x=100/2=50，指数 + 1
    - x=50%2==0 → x=50/2=25，指数 + 1
    - x=25%2≠0 → 停止，p=2 的指数是 2
    
2. x=25>1，minp [25]=5（25 的最小质因数是 5）
    
    - x%5==0 → x=25/5=5，指数 + 1
    - x=5%5==0 → x=5/5=1，指数 + 1
    - x=1%5≠0 → 停止，p=5 的指数是 2
    
3. x=1，循环结束
4. 分解结果：`100 = 2² × 5²`，完美！

## 五、补充考点：试除法判断质数（单个质数判断）

如果只需要判断**一个数 x 是不是质数**，不用筛法，用试除法更快：

cpp

运行

```
bool is_prime(int x) {
    if(x < 2) return false;  // 小于2的数不是质数
    // 试除到√x，因为如果x有一个大于√x的因数，另一个因数一定小于√x
    for(int i=2; i<=x/i; i++) {
        if(x%i == 0) return false;
    }
    return true;
}
```

- 原理：如果 x 是合数，一定有一个因数≤√x，所以试除到√x 就够了，不用试到 x-1
- 适用场景：单个质数判断，批量判断用筛法

## 七、一句话总结（助记）

- **线性筛**：用「最小质因数」批量筛质数，不重复、速度快，还存下每个数的最小质因数
- **质因数分解**：用 minp 数组，快速把数拆成质数相乘，比试除快 100 倍
- 这两个是蓝桥杯数论题的**基础中的基础**，几乎所有数论题都要用到！

## 八、完整可运行小 demo（直接跑一遍就懂）

cpp

运行

```
#include <iostream>
using namespace std;

const int N = 100;
int primes[N], cnt;
int minp[N];
bool st[N];

void get_primes(int n) {
    for(int i=2; i<=n; i++) {
        if(!st[i]) {
            primes[cnt++] = i;
            minp[i] = i;
        }
        for(int j=0; primes[j]*i <=n; j++) {
            int t = primes[j] * i;
            st[t] = true;
            minp[t] = primes[j];
            if(i % primes[j] == 0) break;
        }
    }
}

void divide(int x) {
    cout << x << " 分解为：";
    while(x > 1) {
        int p = minp[x];
        int cnt = 0;
        while(x % p == 0) {
            x /= p;
            cnt++;
        }
        cout << p << "^" << cnt << " ";
    }
    cout << endl;
}

int main() {
    get_primes(100); // 筛2~100的质数

    // 输出2~10的质数
    cout << "2~10的质数：";
    for(int i=0; primes[i]<=10; i++) {
        cout << primes[i] << " ";
    }
    cout << endl;

    // 分解100
    divide(100);
    // 分解12
    divide(12);
    // 分解18
    divide(18);

    return 0;
}
```

plaintext

```
2~10的质数：2 3 5 7 
100 分解为：2^2 5^2 
12 分解为：2^2 3^1 
18 分解为：2^1 3^2 
```

完全正确！
