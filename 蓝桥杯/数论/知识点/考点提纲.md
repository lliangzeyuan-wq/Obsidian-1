# 一、最大公约数 / 最小公倍数（**考频最高，几乎每场都有**）

## 核心考点

1. 欧几里得算法（辗转相除法）求 `gcd(a,b)`
2. 多个数的 gcd 递推求法（你刚做的等差数列题就是这个）
3. 最小公倍数 `lcm(a,b) = a*b / gcd(a,b)`（注意先除后乘防溢出）
4. `gcd(0, x) = x`（关键性质，常考）

## 必背模板

cpp

运行

```
typedef long long ll;
ll gcd(ll a, ll b) {
    a = llabs(a); b = llabs(b);
    while(b) { ll t = b; b = a%b; a = t; }
    return a;
}
ll lcm(ll a, ll b) {
    return a / gcd(a,b) * b; // 先除后乘，防溢出
}
```

## 常考题型

- 等差数列最短长度（求差值 gcd）
- 分数约分
- 多个数的最大公约数
- 互质判断（gcd=1）

# 二、质数筛法 & 质因数分解（**第二高频**）

## 核心考点

1. 埃氏筛（简单，小范围用）
2. **线性筛（欧拉筛）**（省赛标准写法，能求最小质因数）
3. 快速质因数分解（用 minp 数组）
4. 判断质数（试除法）

## 必背模板（线性筛 + 分解）

cpp

运行

```
const int N = 1e6+10;
int primes[N], cnt, minp[N];
bool st[N];

void get_primes(int n) {
    for(int i=2; i<=n; i++) {
        if(!st[i]) primes[cnt++]=i, minp[i]=i;
        for(int j=0; primes[j]*i<=n; j++) {
            st[primes[j]*i] = 1;
            minp[primes[j]*i] = primes[j];
            if(i%primes[j]==0) break;
        }
    }
}
// 质因数分解 x
void divide(int x) {
    while(x>1) {
        int p = minp[x];
        while(x%p==0) x/=p; // 统计指数
    }
}
```

## 常考题型

- 统计质数个数
- 质因数分解求指数
- 约数个数 / 约数和
- 你刚做的**因子链问题**（省赛经典原题）

# 四、快速幂 & 快速幂取模（**必考，尤其是计算大数幂**）

## 核心考点

1. 快速计算 ab
2. 快速计算 abmodmod（防止溢出）
3. 配合逆元、组合数使用

## 必背模板

cpp

运行

```
ll qpow(ll a, ll b, ll mod) {
    ll res = 1;
    while(b) {
        if(b&1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
```

## 常考题型

- 大数幂运算
- 密码学、取模运算

# 六、取模与同余基础（**必懂基础**）

## 核心规则

- (a+b)%mod=(a%mod+b%mod)%mod
- (a∗b)%mod=(a%mod)∗(b%mod)%mod
- 减法要加 mod 再取模：(a−b+mod)%mod

省赛几乎所有大数题都要取模，**不会取模必溢出丢分**。

# 七、欧拉函数（**偶尔考，省赛简单版**）

## 核心公式

ϕ(n)=n∗(1−1/p1​)∗(1−1/p2​)...

含义：1~n 中与 n 互质的数的个数

## 常考题型

- 求互质数个数
- 配合筛法求欧拉函数表

# 八、扩展欧几里得 & 裴蜀定理（**简单考，不深**）

## 核心结论

方程 ax+by=gcd(a,b) 一定有整数解

裴蜀定理：ax+by=c 有解 ⇔ gcd(a,b)∣c

省赛一般只考**判断是否有解**，不考复杂求解。
