# 一、核心本质区别（一句话记住）

1. **`memset`**：C/C++ 通用，**按字节赋值**，只能填**字节大小的值**，速度极快。
2. **`fill`**：C++ 专属，**按元素赋值**，能填**任意值、任意类型**，通用性极强。

---

# 二、详细对比表

表格

| 特性        | memset                            | fill                       |
| :-------- | :-------------------------------- | :------------------------- |
| **语言支持**  | C 语言 / C++ 都能用                    | 仅 C++ 能用（STL 算法）           |
| **赋值单位**  | 按 ** 字节（1Byte）** 赋值               | 按 ** 元素（1 个变量）** 赋值        |
| **可赋值内容** | 只能填 `0~255` 的字节值                  | 任意值（数字、字符、对象都可以）           |
| **支持类型**  | 主要用于 `char` 数组；`int` 数组仅支持 `0/-1` | 所有类型（`int`/`double`/ 字符串等） |
| **头文件**   | `<string.h>` / `<cstring>`        | `<algorithm>`              |
| **速度**    | 极快（底层内存操作）                        | 稍慢（通用型遍历赋值）                |

# 三、最关键的坑！（新手必看）

## 1. memset 不能随便给 int 数组赋值！

`int` 占 **4 个字节**，`memset` 是**一个字节一个字节填**：

```
int a[5];
// 错误！想赋值 1，结果变成 0x01010101 = 16843009
memset(a, 1, sizeof(a)); 

// 正确！只有 0 和 -1 可以用 memset 给 int 数组赋值
memset(a, 0, sizeof(a));  // 全0
memset(a, -1, sizeof(a)); // 全-1
```

## 2. fill 想赋什么值就赋什么值

```
int a[5];
// C++ fill：直接给每个 int 元素赋值 1
fill(a, a+5, 1); 

// 赋值 100、666、任意数都可以
fill(a, a+5, 666); 
```

# 四、用法示例

## 1. memset 用法（C/C++）

```
#include <string.h>
// 1. char 数组：可以赋任意值
char ch[10];
memset(ch, 'A', sizeof(ch)); // 全填 'A'

// 2. int 数组：只能填 0 或 -1
int num[10];
memset(num, 0, sizeof(num)); // 全0 ✅
```

## 2. fill 用法（仅 C++）

```
#include <algorithm>
int num[10];
fill(num, num+10, 888);   // 全888 ✅
fill(num, num+10, -520);  // 全-520 ✅
```

# 五、适用场景总结

### 你该用 memset 的时候：

1. 初始化 **char 数组** 为任意字符
2. 快速把 **int 数组 / 结构体** 清零（`0`）
3. 追求极致速度，只需要填 `0` 或 `-1`

### 你该用 fill 的时候（C++）：

1. 给 **int/double 数组** 赋**任意非 0 值**（比如 1、100、-5）
2. 给 C++ 容器（`vector`、`string`）赋值
3. 不想踩字节赋值的坑，追求安全通用

### 总结

1. **C 语言只有 `memset`，没有 `fill`**；
2. `memset` 按**字节**赋值，快但受限（仅支持 0/-1/char）；
3. `fill` 按**元素**赋值，C++ 专用，通用无坑，支持任意值。
