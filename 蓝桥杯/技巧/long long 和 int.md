# 一、超级口诀（背这个就够了）

**int 存小的，long long 存大的、计算的、模运算的！**

# 二、什么时候用 int

**int 就是普通整数，范围：-2e8 ~ 2e8**

只要满足下面任意一条，就用 **int**：

1. 数组下标
2. 循环变量 i、j、k
3. 输入的数字本身不大（≤ 1e8）
4. 计数、长度、大小

```cpp
int n;
int a[100005];
int cnt[500005];
for (int i=0; i<n; i++) { ... }
```

# 三、什么时候必须用 long long

**只要跟 “结果、乘法、阶乘、排列、组合、模运算、答案” 有关，全部 long long！**

满足任意一条，**必须 long long**：

1. 阶乘数组 fac
2. 逆元数组 inv_fac
3. 快速幂函数返回值
4. 答案 ans
5. 中间计算结果 a、b、c
6. 模运算相关的所有值
7. 超过 int 范围的数


```cpp
long long fac[500005];
long long inv_fac[500005];
long long ans = 0;
long long a = fac[n];
long long pow(...) { ... }
```

# 四、最关键的一句话（蓝桥杯血泪经验）

## **乘法 → 必爆 int → 必须 long long**

## **阶乘 → 必爆 int → 必须 long long**

## **模运算 → 必须 long long**

你看你这道题：

```cpp
fac[i] = fac[i-1] * i % mod;
```

这里 **fac 必须 long long**

因为 `*i` 是乘法，int 一下就爆了！

# 五、最安全的比赛习惯（推荐）

### 你比赛时直接这样写：

1. **循环、下标、输入数字 → int**
2. **所有计算、结果、阶乘、逆元、模运算 → long long**

### 甚至可以直接：

cpp

运行

```cpp
#define int long long
```

写在 main 上面，**全场不用考虑溢出**！

（蓝桥杯非常常用，不会出错）

# 六、给你整理成【考试笔记】

# 蓝桥杯 int /long long 使用规则（必背）

## 1. int 用于：

- 循环变量 i, j, k
- 数组下标
- 输入的原始数字
- 长度、计数、范围小的变量

## 2. long long 用于：

- 阶乘 fac
- 逆元 inv_fac
- 答案 ans
- 所有乘法
- 所有加法（大数）
- 模运算
- 快速幂
- 排列组合计算
- 中间结果 a, b, c

## 3. 黄金规则：

- **看到乘法 → long long**
- **看到阶乘 → long long**
- **看到取模 → long long**
- **看到答案 → long long**

## 4. 最安全写法（比赛推荐）



```cpp
#define int long long
```

加在代码最前面，全程不溢出！
