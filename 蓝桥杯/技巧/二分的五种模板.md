# 闭区间
- 最后找到的位置l == r 
### 等于
```cpp
int l=1,r=n;
while(l<r)
{
	int mid=l+r>>1;
	if(a[mid]>=x) r=mid;
	else l=mid+1;
}

if (a[l] == x) { cout << "找到了，位置是：" << l << endl; } else { cout << "没找到" << endl; }
```


### 一、查找 **第一个 ≥ x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r >> 1;   // 等价于 (l+r)/2，向下取整
    if (a[mid] >= x) r = mid;
    else l = mid + 1;
}
// 最终 l=r 就是第一个 >=x 的位置
```

### 二、查找 **第一个 > x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r >> 1;
    if (a[mid] > x) r = mid;
    else l = mid + 1;
}
```


### 三、查找 **最后一个 ≤ x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r + 1 >> 1;  // 向上取整！必须+1
    if (a[mid] <= x) l = mid;
    else r = mid - 1;
}
```


### 四、查找 **最后一个 < x** 的位置

# 开区间

- **区间定义**：`(l, r)` 开区间
- **初始值**：`l = 0, r = n+1`
- **循环条件**：`while (l + 1 != r)`
- **退出时**：`l 和 r 相邻`（退出的时候r=l+1)，如果是>，>= 那么最后返回的是r；如果< ,<= 那么最后返回的l;
- **mid**：`mid = l + r >> 1`
- **更新规则永远不变**：

    ```cpp
    if (条件满足) r = mid;
    else l = mid;
    ```
    

---

### 1. 找 **第一个 ≥ x** 的位置（lower_bound）
```cpp
int l = 0, r = n+1;
//退出的时候l+1==r
while (l + 1 != r) {
    int mid = l + r >> 1;
    if (a[mid] >= x) r = mid;
    else l = mid;
}
// 答案 = r
```
