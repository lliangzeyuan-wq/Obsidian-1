## 一、查找 **第一个 ≥ x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r >> 1;   // 等价于 (l+r)/2，向下取整
    if (a[mid] >= x) r = mid;
    else l = mid + 1;
}
// 最终 l=r 就是第一个 >=x 的位置
```

## 二、查找 **第一个 > x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r >> 1;
    if (a[mid] > x) r = mid;
    else l = mid + 1;
}
```


## 三、查找 **最后一个 ≤ x** 的位置

```cpp
int l = 1, r = n;
while (l < r) {
    int mid = l + r + 1 >> 1;  // 向上取整！必须+1
    if (a[mid] <= x) l = mid;
    else r = mid - 1;
}
```
