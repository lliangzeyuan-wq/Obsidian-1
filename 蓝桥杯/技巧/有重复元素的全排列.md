## 一、核心结论

当对包含重复元素的序列进行全排列时，**不同的排列数**需要用以下公式计算：

排列数=c1​!×c2​!×⋯×ck​!N!​

- N：序列中元素的总个数
- c1​,c2​,…,ck​：每种不同元素的出现次数

---

## 二、直观理解

1. **无重复情况**：如果所有元素都不相同，总排列数就是 N!。
    
    - 例如：`[1, 2, 3]`，排列数 = 3!=6。
    
2. **有重复情况**：如果有重复元素，交换相同元素的位置不会产生新的排列，因此需要除以这些重复元素的阶乘来消除重复计数。
    
    - 例如：`[2, 2, 3]`，总元素数 N=3，数字 2 出现 c1​=2 次，数字 3 出现 c2​=1 次。
    - 排列数 = 2!×1!3!​=26​=3，分别是 `[2,2,3]`, `[2,3,2]`, `[3,2,2]`。
    

---

## 三、在本题中的应用

在 “黑客” 这道题中，我们需要计算矩阵元素的排列数：

- 矩阵元素总个数 N=n×m=k−2（k 是输入数组的长度）。
- 每个数字 x 在输入中出现的次数为 counts[x]。
- 因此，矩阵元素的不重复全排列数为：排列数=∏(counts[x]!)(k−2)!​

---

## 四、模运算下的实现（蓝桥杯重点）

在算法竞赛中，由于结果可能很大，需要对 109+7 取模。直接做除法会导致错误，因此我们利用**费马小定理**将除法转换为乘法：

a/b MOD mod=a * b^-1 MOD mod

其中 b−1 是 b 在模 mod 下的逆元，可通过快速幂计算：

b^-1=pow(b,mod−2,mod)=b^mod-2 (MOD mod)

### 代码实现步骤：

1. **预处理阶乘**：计算 0!,1!,…,500000! 并存储在 `fac` 数组中。
2. **预处理逆元阶乘**：计算 0!−1,1!−1,…,500000!−1 并存储在 `inv_fac` 数组中。
3. **计算排列数**：
    
    cpp
    
    运行
    
    ```
    ll a = fac[N]; // N = k-2
    for (int x : st) { // st 是所有出现过的数字的集合
        if (counts[x] >= 1) {
            a = a * inv_fac[counts[x]] % mod;
        }
    }
    ```
    
    - `a` 初始化为 N!。
    - 对每个出现过的数字 x，乘以其出现次数阶乘的逆元 inv_fac[counts[x]]，等价于除以 counts[x]!。

## 五、总结

- **公式**：∏(ci​!)N!​
- **本质**：用除法消除相同元素交换带来的重复计数。
- **模运算技巧**：利用逆元将除法转换为乘法，避免直接计算导致的精度和溢出问题。
