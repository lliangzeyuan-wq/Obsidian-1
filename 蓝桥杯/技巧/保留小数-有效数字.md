在 C++ 中保留特定位数的小数输出，==**必须使用 `<iomanip>` 头文件**==，核心靠两个关键字配合实现：

`fixed`（固定小数格式）+ `setprecision(n)`（设置保留 `n` 位小数）

---
- ==**set**：英文意思是 “设置”==
- ==**precision**：英文意思是 “精度、精确度”==

==所以，`setprecision` 的字面意思就是 **“设置精度”**。==
## 一、最简写法（直接套你的代码）

你题目要求**保留 3 位小数**，代码如下：

cpp

运行

```
#include <iostream>
#include <iomanip>  // 必须加这个头文件！
using namespace std;

int main() {
    double num = 0.54032;  // 举例概率
    
    // 固定小数格式 + 保留3位小数
    cout << fixed << setprecision(3) << num << endl; 
    return 0;
}
```

✅ 输出结果：`0.540`

---

## 二、核心规则（新手必记）

1. **`setprecision(n)`**
    
    - 不加 `fixed`：表示保留 **n 位有效数字**
    - 加 `fixed`：表示保留 **n 位小数**（这才是你要的）
    
2. **四舍五入**：C++ 会自动四舍五入，不用手动处理
3. **生效范围**：设置一次后，**后续所有 cout 输出都生效**

---

## 三、对比演示（一看就懂）

cpp

运行

```
double x = 12.34567;

// 1. 不加 fixed：保留3位有效数字
cout << setprecision(3) << x << endl;   // 输出 12.3

// 2. 加 fixed：保留3位小数（正确用法）
cout << fixed << setprecision(3) << x; // 输出 12.346
```

double prob = (total_angle - total_danger) / total_angle;

## 总结

1. 保留小数 → **必须写 `fixed`**
2. 保留几位 → `setprecision(数字)`
3. 必须加头文件 → `#include <iomanip>`
4. 你的题目用：`fixed << setprecision(3)` 完美适配
