# C++ `std::map` 自动累加用法笔记

## 核心用法

cpp

运行

```
map<int, int> mp;
mp[key] += value;
```

### 作用

- 若 `key` 已存在：将 `value` 累加到对应 `value` 上。
- 若 `key` 不存在：自动创建键值对 `{key: 0}`，再将 `value` 累加到 `0` 上。

---

## 场景示例（训练士兵）

cpp

运行

```
map<int, int> mp;
// 士兵1：c=2, p=5
mp[2] += 5;  // mp: {2:5}
// 士兵2：c=4, p=2
mp[4] += 2;  // mp: {2:5, 4:2}
// 士兵3：c=2, p=3
mp[2] += 3;  // mp: {2:8, 4:2}
```

### 含义

- `mp[c]`：所有需要训练 `c` 次的士兵，单次训练成本总和。
- `map` 会自动按 `key`（训练次数）升序排序，方便后续贪心处理。

---

## 等价手动写法

cpp

运行

```
if (mp.find(key) != mp.end()) {
    mp[key] += value;
} else {
    mp[key] = value;
}
```

---

## 优点

- 代码简洁：一行完成 “统计 + 累加”。
- 自动排序：`map` 按键升序排列，适配 “从少到多处理” 的贪心逻辑。
