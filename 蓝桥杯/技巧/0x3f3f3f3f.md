# 0x3f3f3f3f 超通俗解释（一看就懂）

`0x3f3f3f3f` 是**C++ 算法里最常用的 “无穷大” 值**，专门用来表示一个**足够大、不会溢出、又安全的数**。

---

## 1. 它到底是什么？

- `0x` 开头 = **十六进制**
- `0x3f3f3f3f` 转成十进制 = **1061109567**
- ==大约 **1e9**，==比题目里常见的最大值大得多，足够当作 “无穷大”

---

## 2. 为什么不用 0x7fffffff？

很多人会问：不是有个最大 int `0x7fffffff` 吗？

为什么非要用 `0x3f3f3f3f`？

### 最大区别：**加法不会溢出！**

- `0x7fffffff` + 1 = **变成负数（溢出报错）**
- `0x3f3f3f3f` + `0x3f3f3f3f` = **还是正数，不溢出**

算法题里经常要 `dist[u] + w`，用 `0x3f3f3f3f` 最安全。

---

## 3. 它在代码里的作用

你截图里这句：

cpp

运行

```
int ans = 0x3f3f3f3f;
```

意思就是：

> **把答案 ans 先设成一个 “超级大的数”**
> 
> 后面找到更小的合法答案，再把 ans 更新掉。

就像：

- 先把最高分设为 10000
- 然后一个个比较，最后留下真正的最高分

---

## 4. 最常用场景（背下来）

cpp

运行

```
// 初始化无穷大
const int INF = 0x3f3f3f3f;

// 求最小值时用
int ans = INF;
ans = min(ans, 新值);
```

✅ 大小约 1e9，够用

✅ **相加不溢出**，不会错

✅ 专门用来：**初始化最小值答案**
