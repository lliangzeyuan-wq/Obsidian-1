# 1️⃣ 最常用：把 **二维布尔数组压成 bitset**（省内存 + 加速）

就是你这道题的用法！

**凡是 n=5000 左右的区间 DP，几乎必用！**

cpp

运行

```
const int N = 5005;
vector<bitset<N>> f(n);   // 等价 bool f[n][N]
```

**用法一模一样：**

cpp

运行

```
f[l][r] = 1;
if(f[l][r]) ...
```

**比赛看到：**

- n ≥ 2000
- 要开二维 bool 数组
    
    👉 **直接上 bitset，不会爆内存、不会超时**


# 2️⃣ 背包问题：bitset 加速 **01 背包**（暴力变飞快）

蓝桥杯常考：能不能凑出某个重量

普通背包：

cpp

运行

```
bool dp[5005];
```

bitset 版（快 64 倍）：

cpp

运行

```
bitset<5005> dp;
dp[0] = 1;
for(int x : a) dp |= dp << x;

// 最后 dp[i] = 1 表示能凑出 i
```

**直接背！**

看到**子集和、能不能凑数、01 背包**就用这个！
