你现在只需要记住一句话：

# 👉 **在蓝桥杯里，99% 情况用 unordered_set 更快！**

---

# 1. 最核心区别（必背）

|特性|set|unordered_set|
|---|---|---|
|**内部结构**|平衡二叉树|哈希表|
|**是否有序**|**自动从小到大排序**|**无序**|
|**查询速度**|慢 O (log n)|**超快 O (1)**|
|**蓝桥杯推荐**|很少用|**几乎都用它**|

---

# 2. 人话翻译

### set = 有序列表

你放进去 3、1、2，它会自动排成 **1、2、3**。

但**速度慢**。

### unordered_set = 乱序列表

你放进去什么顺序就是什么顺序，**不排序**。

但**速度超级快**！

---

# 3. 回到你那行代码

cpp

运行

```
unordered_set<int> st(nums, nums + (n + 2));
```

### 我们要的是什么？

**只需要：去重 + 快速查找**

**不需要：排序**

所以用 **unordered_set 最完美**！

---

# 4. 什么时候用 set？

只有一种情况：

**你必须让元素自动从小到大排好序**

否则一律用 unordered_set！

---

# 5. 超级总结（你只记这个）

1. **unordered_set = 快 + 不排序 → 蓝桥杯神器**
2. **set = 慢 + 自动排序 → 很少用**
