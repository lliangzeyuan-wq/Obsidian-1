## 2. Floyd 全源最短路径算法

### 核心功能

求**图中任意两个节点之间**的最短路径（全源最短路径），一次计算得到所有点对的最短距离。

### 适用条件

- 可处理**含负权边的图**，但**不能有负权环**（否则最短路径会无限小，无法计算）。
- 也适用于正权图。

### 时间复杂度

- `O(n³)`（三重循环，枚举所有中间节点`k`，再枚举所有点对`(i,j)`，判断`i→k→j`是否比`i→j`更短）。
- 仅适用于**节点数较少的图**（`n≤1000`时可运行，`n>1000`效率极低）。

### 核心思想

动态规划：`dist[i][j]` 表示从`i`到`j`的最短路径，通过三重循环更新：

cpp

运行

```
for (k = 1; k <= n; k++)
  for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j++)
      dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

### 一、题目与算法分析

这是一道**多源最短路径**问题：需要预先计算所有景点之间的最短路径，再回答多次查询。

- 数据规模：`N ≤ 400`，`Q ≤ 10³`
- 算法选择：**Floyd 算法**（时间复杂度 `O(N³)`，400³=6400 万，完全可以通过）
- 核心思想：动态规划，通过 “中转节点” 逐步更新所有点对的最短路径。

---

### 二、Floyd 算法核心原理

1. **状态定义**：`dist[i][j]` 表示从节点 `i` 到节点 `j` 的最短路径长度。
2. **初始化规则**：
    
    - 自己到自己：`dist[i][i] = 0`
    - 直接相连的节点：`dist[i][j] = 边权w`（双向图需同时设置 `dist[j][i] = w`）
    - 不直接相连的节点：初始化为极大值（代表不可达，如 `1e18`）
    
3. **状态转移公式**：
    
    对每个中间节点 `k`，尝试用 `k` 作为中转点更新路径：
    
    cpp
    
    运行
    
    ```
    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
    ```
    
    含义：`i` 到 `j` 的最短路径，要么是原路径，要么是 `i→k→j` 的路径（`i` 到 `k` 的最短路径 + `k` 到 `j` 的最短路径）。
4. **最终结果**：三层循环结束后，`dist[i][j]` 就是 `i` 到 `j` 的最短路径长度。

### 三、C++ 完整代码（带详细注释）

cpp

运行

```
#include <iostream>
#include <algorithm>
using namespace std;

// 定义无穷大：要足够大，避免溢出（边权最大1e9，最多400条边，总和4e11，1e18远大于此）
const long long INF = 1e18;
// 节点编号从1开始，N最大400，所以数组开405足够
long long dist[405][405];
int N, M, Q;

int main() {
    // 加速输入输出（避免大数据量时超时）
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // -------------------------- 1. 初始化距离数组 --------------------------
    for (int i = 1; i <= 400; ++i) {
        for (int j = 1; j <= 400; ++j) {
            if (i == j) {
                dist[i][j] = 0; // 自己到自己的距离为0
            } else {
                dist[i][j] = INF; // 初始化为不可达
            }
        }
    }

    // -------------------------- 2. 读入边数据 --------------------------
    cin >> N >> M >> Q;
    for (int i = 0; i < M; ++i) {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        // 处理重边：只保留最短的边
        if (w < dist[u][v]) {
            dist[u][v] = w;
            dist[v][u] = w; // 道路是双向的
        }
    }

    // -------------------------- 3. Floyd核心算法 --------------------------
    // 顺序：k（中转节点）→ i（起点）→ j（终点）
    for (int k = 1; k <= N; ++k) {
        for (int i = 1; i <= N; ++i) {
            for (int j = 1; j <= N; ++j) {
                // 如果i到k 或 k到j不可达，无法用k中转，跳过
                if (dist[i][k] == INF || dist[k][j] == INF) {
                    continue;
                }
                // 尝试用k中转，更新i到j的最短路径
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }

    // -------------------------- 4. 处理查询 --------------------------
    for (int i = 0; i < Q; ++i) {
        int st, ed;
        cin >> st >> ed;
        if (dist[st][ed] == INF) {
            cout << -1 << '\n'; // 不可达时输出-1（题目若保证连通可省略）
        } else {
            cout << dist[st][ed] << '\n';
        }
    }

    return 0;
}
```

---

### 四、关键细节说明

1. **数据类型**：必须用 `long long`，因为边权最大 `1e9`，400 条边总和可达 `4e11`，超过 `int` 范围（`int` 最大约 2e9），否则会溢出。
2. **重边处理**：读入边时，通过 `if (w < dist[u][v])` 只保留最小边权，避免重复边导致路径计算错误。
3. **不可达判断**：若查询结果仍为 `INF`，说明两点间无路径，输出 `-1`（题目若保证连通，可省略此判断）。
4. **输入加速**：`ios::sync_with_stdio(false); cin.tie(nullptr);` 用于加速输入，避免大数据量时超时。

---

### 五、时间复杂度

- 初始化：`O(N²)`
- 读入边：`O(M)`
- Floyd 核心：`O(N³)`（三层循环）
- 查询：`O(Q)`
- 总复杂度：`O(N³ + M + Q)`，对 `N=400` 完全可行。
