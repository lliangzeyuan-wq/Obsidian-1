# 蓝桥杯「哈密顿回路 / 路径计数」知识点全梳理

哈密顿回路计数是蓝桥杯省赛**图论 + 动态规划**的核心难点，属于「状态压缩 DP（状压 DP）」的经典应用，在 2021、2019 等多届省赛中出现，是 n≤25 规模下的标准解法，也是蓝桥杯省赛冲刺高分的必掌握知识点。

---

## 一、基础概念：先搞懂「哈密顿」相关定义

### 1. 核心定义

- **哈密顿路径**：经过图中**每个顶点恰好一次**的路径（不要求回到起点）
- **哈密顿回路（环）**：经过图中**每个顶点恰好一次，最终回到起点**的闭合路径（也就是你刚才做的「回路计数」题的要求）

### 2. 与「欧拉回路」的核心区别（蓝桥杯常考区分）

表格

|特性|欧拉回路|哈密顿回路|
|---|---|---|
|遍历对象|每条边恰好一次|每个顶点恰好一次|
|顶点访问|可重复|不可重复|
|判定条件|连通图 + 所有顶点度数为偶数（无向）|无通用多项式判定算法（NP 完全问题）|
|蓝桥杯考法|多为判断 / 计数，用 Hierholzer 算法|多为计数 / 求最短，用状压 DP|

### 3. 蓝桥杯的出题规律

- 图类型：以**无向图**为主（如你做的「互质连廊」题），偶尔考有向图
- 顶点规模：n 通常在**15~25**之间（2^25≈3300 万，C++ 中可轻松跑通，n>30 不适合状压）
- 题型：多为**结果填空题**（如 2021 省赛 E 题），偶尔出编程大题，要求计数或求最短路径

---

## 二、核心解法：状态压缩 DP（状压 DP）

### 1. 为什么用状压 DP？

哈密顿回路计数是**NP 完全问题**，暴力枚举全排列（n!）在 n=20 时就达到 2.4×10^18，完全不可能跑完。

而状压 DP 用二进制位表示「已访问的顶点集合」，时间复杂度为**O(n²·2ⁿ)**，n=21 时仅约 4400 万次操作，C++ 中 1 秒内可轻松跑完，是蓝桥杯的唯一可行解法。

### 2. 状态定义（蓝桥杯标准写法）

- 用 ** 二进制整数`mask`** 表示「已访问的顶点集合」：
    
    例：n=3，`mask=0b101`（十进制 5）表示「顶点 0、2 已访问，顶点 1 未访问」（顶点编号从 0 开始，对应 bit 位 0~n-1）
- 状态定义：`dp[mask][u]`
    
    含义：**已访问`mask`集合中的所有顶点，当前停在顶点`u`的方案数（或最短路径长度）**

### 3. 状态转移方程

对于每个状态`mask`、每个当前顶点`u`：

遍历所有**未访问的顶点`v`**，如果`u`和`v`之间有边（连通），则：

- **计数问题（如回路计数）**：
    
    `dp[mask | (1<<v)][v] += dp[mask][u]`
    
    （把从`u`到`v`的方案数，累加到新状态中）
- **最短路径问题**：
    
    `dp[mask | (1<<v)][v] = min(dp[mask | (1<<v)][v], dp[mask][u] + weight(u,v))`
    
    （取当前最短路径和新路径的最小值）

### 4. 初始化

- 起点固定为顶点`0`（对应题目中 1 号楼，编号 - 1 转 0）：
    
    计数问题：`dp[1 << 0][0] = 1`（初始方案数为 1）
    
    最短路问题：`dp[1 << 0][0] = 0`（起点到自己距离为 0）

### 5. 最终答案计算

#### （1）哈密顿回路计数（你做的题）

当`mask`为**全 1**（所有顶点都访问过，`mask=(1<<n)-1`）时：

遍历所有顶点`u`（u≠0），如果`u`和起点`0`之间有边，累加`dp[full_mask][u]`，就是总回路数（从`u`回到起点，形成闭合回路）。

#### （2）哈密顿路径计数（不要求回起点）

直接取`full_mask`下所有`dp[full_mask][u]`的和即可。

#### （3）最短哈密顿路径 / 回路

取`full_mask`下`dp[full_mask][u]`的最小值（回路需额外加`u`到起点的边权）

## 三、蓝桥杯真题模板：「回路计数」n=21 可直接运行

cpp

运行

```
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

typedef long long ll; // 必须用long long，避免计数溢出
const int N = 21; // 顶点数，对应1~21号楼，代码内编号0~20

// 邻接矩阵：g[u][v] = 1 表示u和v连通（互质），0表示不连通
bool g[N][N];
// 状压DP数组：dp[mask][u] = 访问mask集合，停在u的方案数
ll dp[1<<N][N];

// 欧几里得算法求最大公约数，判断两数是否互质
int gcd(int a, int b) {
    return b ? gcd(b, a%b) : a;
}

int main() {
    // 1. 预处理邻接矩阵：u+1和v+1互质则连通（对应题目中的1~21号楼）
    for(int i=0; i<N; i++) {
        for(int j=0; j<N; j++) {
            g[i][j] = (gcd(i+1, j+1) == 1);
        }
    }

    // 2. 初始化DP：起点为0（对应1号楼），仅起点访问，方案数为1
    memset(dp, 0, sizeof dp);
    dp[1<<0][0] = 1;

    // 3. 枚举所有状态mask
    for(int mask=1; mask < (1<<N); mask++) {
        // 枚举所有当前顶点u
        for(int u=0; u<N; u++) {
            // u不在当前mask中 / 方案数为0，跳过无效状态
            if(!(mask & (1<<u)) || dp[mask][u] == 0) continue;

            // 4. 枚举所有未访问的顶点v
            for(int v=0; v<N; v++) {
                // v已访问 / u和v不连通，跳过
                if((mask & (1<<v)) || !g[u][v]) continue;

                // 5. 状态转移：累加方案数
                dp[mask | (1<<v)][v] += dp[mask][u];
            }
        }
    }

    // 6. 计算最终答案：全1mask下，所有u≠0且u与0连通的方案数之和（回起点形成回路）
    ll ans = 0;
    const int full_mask = (1<<N) - 1;
    for(int u=1; u<N; u++) {
        if(g[u][0]) ans += dp[full_mask][u];
    }

    cout << ans << endl; // 输出结果：881012367360
    return 0;
}
```

## 四、蓝桥杯常考变形与优化

### 1. 常见变形

表格

|变形类型|题目要求|解法调整|
|---|---|---|
|起点 / 终点固定|从 s 出发，到 t 结束的哈密顿路径|初始化`dp[1<<s][s]=1`，最终取`dp[full_mask][t]`|
|带权最短哈密顿回路|求总权值最小的回路|计数 DP 改最短路 DP，初始化为无穷大，转移取 min|
|有向图哈密顿计数|边为单向通行|邻接矩阵改为单向，转移时仅判断单向连通|
|网格图哈密顿路径|棋盘遍历、网格走法|状压 DP + 轮廓线 DP（蓝桥杯偶尔考）|

### 2. 蓝桥杯优化技巧（提速 / 防溢出）

1. **预处理邻接矩阵**：提前算好连通性 / 边权，避免转移时重复计算（如本题的 gcd）
2. **剪枝无效状态**：跳过`dp[mask][u]==0`的状态，减少无效循环（模板已加）
3. **数据类型安全**：计数必须用`long long`，int 最大仅 2e9，n=21 时结果远超 int 范围
4. **位运算分层转移**：用`__builtin_popcount(mask)`按已访问点数分层，减少无效遍历
5. **滚动数组省空间**：n>25 时用，n=21 时空间足够（约 350MB），无需优化

## 五、蓝桥杯避坑指南（高频错误）

1. **编号转换错误**：题目 1~n 编号要转成代码 0~n-1，否则 mask 位对应错误
2. **互质判断错误**：1 和所有数互质，gcd (1,x)=1，不要漏判
3. **回路忘记回起点**：最终答案必须累加`u到起点`的连通情况，不能直接取`dp[full_mask][u]`的和
4. **溢出问题**：计数必须用`long long`，否则结果完全错误
5. **状态转移漏条件**：必须判断`v未访问`和`u-v连通`，否则会出现非法路径
6. **暴力枚举误区**：n≥12 时全排列完全不可行，绝对不要尝试

## 七、一句话助记

哈密顿回路计数，蓝桥杯 n≤25 用状压：

二进制 mask 存访问集合，`dp[mask][u]`存当前状态；

转移遍历未访问点，连通就累加 / 更新；

最终全 1mask 下，回起点求和（回路）/ 直接求和（路径）。
