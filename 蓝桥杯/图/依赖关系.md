# 依赖关系是什么？

**依赖关系 = 先后顺序 = 必须先做 A，才能做 B**

B 依赖 A → 没有 A 就不能做 B，A 是 B 的**前提条件**。

---

## 1. 生活中的依赖关系（秒懂）

举 3 个最简单的例子：

1. 你要**穿鞋**，必须先**穿袜子**
    
    → 穿鞋 依赖 穿袜子
2. 你要**写作业**，必须先**打开书包**
    
    → 写作业 依赖 打开书包
3. 你要**打游戏**，必须先**打开电脑**
    
    → 打游戏 依赖 打开电脑

**这就是依赖：后做的事，必须等前面的事完成。**

图里的**箭头 `→`**，就是**依赖关系**！

规则：`A → B` = **B 依赖 A**

你图里的箭头：

1. 必须先做 **1**，才能做 **4、6**
    
    → 4、6 依赖 1
2. 必须先做 **4、6**，才能做 **2**
    
    → 2 依赖 4、6
3. 必须先做 **2**，才能做 **5**
    
    → 5 依赖 2
4. **1** 没有任何依赖（没人指向它），所以**第一个做**

---

## 3. 为什么要无环？（关键）

如果出现**环**（循环依赖）：

比如 `A→B`，`B→A`

→ A 依赖 B，B 依赖 A

→ 先做 A？不行，要先做 B

→ 先做 B？不行，要先做 A

**死循环，永远做不了！**

而你这张图是**无环**的，没有死循环，所以能按顺序一步步完成。
