### 使得外界无法使用构造函数和拷贝构造函数
- 从而保证一个类只能有一个对象
**方法1**
- 将他们设为delete，即禁用
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
	TaskQueue() = delete;
	TaskQueue(const TaskQueue& t) = delete;
private:
};
```
**方法2**
- 设为私有
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
private:
	TaskQueue() {};
	TaskQueue(const TaskQueue& t) {};
};
```
**方法3**
- shi'you
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
private:
	TaskQueue() = default;
	TaskQueue(const TaskQueue& t) = default;
};
```
