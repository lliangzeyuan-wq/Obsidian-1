### 使得外界无法使用构造函数和拷贝构造函数、拷贝赋值操作符重载
- 从而保证一个类只能有一个对象
**方法1**
- 将他们设为delete，删除了，即禁用
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
	TaskQueue() = delete;
	TaskQueue(const TaskQueue& t) = delete;
	TaskQueue& operator=(const TaskQueue& t) = delete;

private:
};
```
**方法2**
- 设为私有
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
private:
	TaskQueue() {};
	TaskQueue(const TaskQueue& t) {};
	TaskQueue& operator=(const TaskQueue& t) {};

};
```
**方法3**
- 私有的默认构造，和方法2的写法差不多
```cpp
#include<iostream>
using namespace std;
class TaskQueue {
public:
private:
	TaskQueue() = default;
	TaskQueue(const TaskQueue& t) = default;
	TaskQueue& operator=(const TaskQueue& t) = default;

};
```

- 现在这个类已经无法在外边创建任何对象了，那么怎么得到类的实例啊，只有通过设立一个静态的对象，通过类名来访问
