# 1. 原子变量

原子变量是指使用 `std::atomic` 模板类定义的变量。这些变量提供了对其所表示的值进行原子操作的能力。原子变量确保在多线程环境中，对变量的读写操作是线程安全的，即操作不会被其他线程中断或干扰。

---

### 原子变量的特性

- **原子性**：对原子变量的读、写、修改操作是不可分割的，即操作要么完全完成，要么完全不完成。
- **无锁**：原子操作不需要使用锁机制，因此不会引起线程上下文切换，具有更高的性能。
- **易用性**：C++ 标准库提供了一组易于使用的原子操作接口，简化了多线程编程中的同步问题。

#### 定义原子变量
```cpp
#include<atomic>
std::atomic<int>atomicInt(0);
```

### 2. 原子操作

原子操作是指对原子变量进行的**不可分割**的操作。不可分割的意思是这些操作要么完全执行，要么完全不执行，不会在执行过程中被其他线程打断。这些操作包括基本的读取、写入、交换、比较并交换（CAS）以及一些算术和按位操作。

### 原子操作是怎么产生的
![[Pasted image 20260218205152.png]]

c

运行

```
int x = 1  // 初始值
```

#### 线程 A：`x = x + 1;`

asm

```
mov eax, dword [x]   ; 从内存x中读取值到寄存器eax
add eax, 1           ; 寄存器eax的值加1
mov dword [x], eax   ; 将寄存器eax的值写回内存x
```

#### 线程 B：`x = x + 1;`

asm

```
mov eax, dword [x]   ; 从内存x中读取值到寄存器eax
add eax, 1           ; 寄存器eax的值加1
mov dword [x], eax   ; 将寄存器eax的值写回内存x
```

---

#### 理想情况（不混乱）

线程 A 和线程 B 的操作完全串行执行，最终 `x = 3`。

#### 实际可能的情况

1. 线程 A 执行：`mov eax, dword [x]` → `eax = 1`
2. 线程 A 执行：`add eax, 1` → `eax = 2`
3. 线程切换，线程 B 执行：`mov eax, dword [x]` → `eax = 1`（此时内存中 x 的值仍为 1）
4. 线程 B 执行：`add eax, 1` → `eax = 2`
5. 线程切换回线程 A 执行：`mov dword [x], eax` → 内存中 `x = 2`
6. 线程 B 执行：`mov dword [x], eax` → 内存中 `x = 2`

最终结果：`x = 2`，而非预期的 `3`。这是因为 `x = x + 1` 并非原子操作，在多线程环境下被打断，导致了**数据竞争**。
