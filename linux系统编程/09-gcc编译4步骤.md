- gcc编译4步骤：预处理、编译、汇编、链接
![[Pasted image 20260312205915.png]]
### 1. 预处理（Preprocessing）

- 做的事：
    
    - 处理 `#include` 头文件，把头文件内容直接展开到代码里
    - 处理 `#define` 宏定义，把宏替换成实际内容
    - 去掉注释
    
- 输出：`.i` 文件（预处理后的纯 C 代码）

### 2. 编译（Compilation）

- 做的事：
    
    - ==把预处理后的 C 代码，翻译成汇编代码（`.s` 文件）==
    - 这一步会做**语法检查、类型检查、函数声明检查**
    
- 你的警告 `implicit declaration of function` 就是在这里触发的！

### 3. 汇编（Assembly）

- 做的事：
    
    - 把汇编代码翻译成机器码，生成目标文件（`.o` 文件）
    - 目标文件里只有二进制指令，没有外部函数的地址
    
- 输出：`.o` 目标文件

### 4. 链接（Linking）

- 做的事：
    
    - 把多个 `.o` 文件、静态库 / 动态库里的代码合并在一起
    - 给外部函数（比如 `add`/`sub`/`div1`）填上最终的内存地址
    
- 输出：可执行文件（比如你生成的 `test`）
