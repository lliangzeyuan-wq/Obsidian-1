- 父进程fork() 不为0 ，那么继续进行下一个 for循环 ，而子进程fork()为0，跳出循环。 子进程继续往下执行，通过sleep阻塞，按照顺序打印， 然后当父进程执行完 for循环 后，5== i , 阻塞之后打印出，"I'm parent" .
- 最终是一个父进程产生了5个子进程

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <pthread.h>

int main(int argc , char * argv[])
{

	int i;
	
	for(i=0;i<5;++i)
	{
		if( fork()==0 )
		{
			break;
		}
	}

	if( 5 ==i )
	{
		sleep(5);
		printf("I'm parent\n");
	}
	else{
		sleep(i);
		printf("I'm %dth child\n" , i+1);
	}
	return 0;
	
}
```
