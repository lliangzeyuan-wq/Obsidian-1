# 常用信号一览表


### Linux 常规信号一览表（可直接复制）

表格

| 编号    | 信号名                     | 触发事件                               | 默认动作                  | 英文意思             |
| :---- | :---------------------- | :--------------------------------- | :-------------------- | ---------------- |
| 1     | `SIGHUP`                | 用户退出 shell 时，该 shell 启动的所有进程将收到此信号 | 终止进程                  | HUP ： hang up 挂断 |
| 2     | `SIGINT`                | 用户按下`<Ctrl+C>`，终端向当前进程发送信号         | 终止进程                  |                  |
| 3     | `SIGQUIT`               | 用户按下`<Ctrl+\>`，终端向当前进程发送信号         | 终止进程（生成 core 文件）      |                  |
| 4     | `SIGILL`                | CPU 检测到进程执行了非法指令                   | 终止进程（生成 core 文件）      |                  |
| 5     | `SIGTRAP`               | 由断点指令或 trap 指令触发                   | 终止进程（生成 core 文件）      |                  |
| 6     | `SIGABRT`               | 调用`abort()`函数时触发                   | 终止进程（生成 core 文件）      |                  |
| 7     | `SIGBUS`                | 非法访问内存地址（含内存对齐错误）                  | 终止进程（生成 core 文件）      |                  |
| 8     | `SIGFPE`                | 致命运算错误（除 0、溢出、浮点错误等）               | 终止进程（生成 core 文件）      |                  |
| 9     | `SIGKILL`               | 无条件强制终止进程                          | 终止进程（不可被忽略 / 捕获 / 阻塞） |                  |
| 10    | `SIGUSR1`               | 用户自定义信号                            | 终止进程                  |                  |
| 11    | `SIGSEGV`               | 无效内存访问（段错误）                        | 终止进程（生成 core 文件）      |                  |
| 12    | `SIGUSR2`               | 第二个用户自定义信号                         | 终止进程                  |                  |
| 13    | `SIGPIPE`               | 向没有读端的管道写入数据                       | 终止进程                  |                  |
| 14    | `SIGALRM`               | `alarm()`设置的定时器超时                  | 终止进程                  |                  |
| 15    | `SIGTERM`               | `kill`命令默认发送的信号，请求进程正常退出           | 终止进程（可被捕获 / 忽略）       |                  |
| 16    | `SIGSTKFLT`             | 早期 Linux 栈错误信号，现保留兼容               | 终止进程                  |                  |
| 17    | `SIGCHLD`               | 子进程状态改变（退出 / 暂停）时发送给父进程            | 忽略信号                  |                  |
| 18    | `SIGCONT`               | 恢复已暂停的进程                           | 继续 / 忽略               |                  |
| 19    | `SIGSTOP`               | 强制暂停进程执行                           | 暂停进程（不可被忽略 / 捕获 / 阻塞） |                  |
| 20    | `SIGTSTP`               | 用户按下`<Ctrl+Z>`，暂停终端交互进程            | 暂停进程                  |                  |
| 21    | `SIGTTIN`               | 后台进程尝试读取终端控制台                      | 暂停进程                  |                  |
| 22    | `SIGTTOU`               | 后台进程尝试向终端输出数据                      | 暂停进程                  |                  |
| 23    | `SIGURG`                | 套接字收到紧急数据（如网络带外数据）                 | 忽略信号                  |                  |
| 24    | `SIGXCPU`               | 进程 CPU 使用时间超过限制                    | 终止进程                  |                  |
| 25    | `SIGXFSZ`               | 进程写入的文件超过最大长度限制                    | 终止进程                  |                  |
| 26    | `SIGVTALRM`             | 虚拟时钟超时（仅计算用户态 CPU 时间）              | 终止进程                  |                  |
| 27    | `SIGPROF`               | 性能时钟超时（含用户态 + 系统态 CPU 时间）          | 终止进程                  |                  |
| 28    | `SIGWINCH`              | 终端窗口大小改变时触发                        | 忽略信号                  |                  |
| 29    | `SIGIO`                 | 异步 I/O 事件就绪时触发                     | 忽略信号                  |                  |
| 30    | `SIGPWR`                | 系统电源故障（如 UPS 低电量）                  | 终止进程                  |                  |
| 31    | `SIGSYS`                | 进程调用了无效的系统调用                       | 终止进程（生成 core 文件）      |                  |
| 34~64 | `SIGRTMIN` ~ `SIGRTMAX` | 实时信号，无固定含义，可由用户自定义                 | 终止进程                  |                  |
