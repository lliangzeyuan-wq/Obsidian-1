

### 信号集操作函数：

c

运行

```
sigset_t set;  // 自定义信号集。

int sigemptyset(sigset_t *set);    // 清空信号集
int sigfillset(sigset_t *set);     // 全部置1
int sigaddset(sigset_t *set, int signum);   // 将一个信号添加到集合中
int sigdelset(sigset_t *set, int signum);   // 将一个信号从集合中移除
int sigismember(const sigset_t *set, int signum); // 判断一个信号是否在集合中。在-->1，不在-->0
```

### 设置信号屏蔽字和解除屏蔽：

c

运行

```
int sigprocmask(int how, const sigset_t *set, sigset_t *oldset);
/*
how:
    SIG_BLOCK:      设置阻塞，新增屏蔽某些信号，不影响之前已屏蔽的信号
    SIG_UNBLOCK:    取消阻塞用途 ， 只放开指定几个信号，其余屏蔽状态不动
    SIG_SETMASK:    用自定义set替换mask，旧 mask 全部作废
set：    自定义set
oldset： 旧有的 mask。
*/
```
