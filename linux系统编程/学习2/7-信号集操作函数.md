

### 信号集操作函数：

```c
sigset_t set;  // 自定义信号集。

int sigemptyset(sigset_t *set);    // 清空信号集
int sigfillset(sigset_t *set);     // 全部置1
int sigaddset(sigset_t *set, int signum);   // 将一个信号添加到集合中
int sigdelset(sigset_t *set, int signum);   // 将一个信号从集合中移除
int sigismember(const sigset_t *set, int signum); // 判断一个信号是否在集合中。在-->1，不在-->0
```

### 设置信号屏蔽字和解除屏蔽：

# sigprocmask 函数笔记

## 函数原型

```c
int sigprocmask(int how, const sigset_t *set, sigset_t *oldset);
```

**功能：修改==进程 PCB 内==的信号屏蔽字，设置 / 解除信号阻塞**

## 参数说明

1. **how：修改方式（3 种宏）**

- `SIG_BLOCK`：**追加阻塞**，把 set 里的信号新增加入屏蔽字，原有被屏蔽信号保持不变
- `SIG_UNBLOCK`：**局部解除阻塞**，仅放开 set 内指定信号，其余信号屏蔽状态不变
- `SIG_SETMASK`：**整体替换**，直接用 set 覆盖原有全部屏蔽字，旧屏蔽规则作废

1. **set**：自定义信号集，本次要操作的信号集合；传 NULL 则不修改屏蔽字
2. **oldset**：传出参数，保存**修改之前旧的信号屏蔽字**；不需要备份旧掩码可传 NULL

- 返回值：
	- **成功返回：0**
	- **失败返回：-1**，同时会设置全局错误码`errno`，可用`perror()`打印错误信息。
