# 5 文件操作

程序运行时产生的数据都属于临时数据，程序一旦运行结束都会被释放。

通过文件可以将数据持久化。

C++ 中对文件操作需要包含头文件 `<fstream>`。

---

## 文件类型

文件类型分为两种：

1. **文本文件**：文件以文本的 ASCII 码形式存储在计算机中。
2. **二进制文件**：文件以数据的二进制形式存储在计算机中，用户一般不能直接读懂它们。

---

## 操作文件的三大类

1. `ofstream`：写操作
2. `ifstream`：读操作
3. `fstream`：读写操作

---

## 5.1.1 写文件

写文件步骤如下：

1. **包含头文件**

    ```cpp
    #include <fstream>
    ```
    
2. **创建流对象**
    
    cpp
    
    运行
    
    ```
    ofstream ofs;
    ```
    
3. **打开文件**
    
    cpp
    
    运行
    
    ```
    ofs.open("文件路径", 打开方式);
    ```
    
4. **写数据**
    
    cpp
    
    运行
    
    ```
    ofs << "写入的数据";
    ```
    
5. **关闭文件**
    
    cpp
    
    运行
    
    ```
    ofs.close();
    ```
    

---

## 文件打开方式

|打开方式|解释|
|:--|:--|
|`ios::in`|为读文件而打开文件|
|`ios::out`|为写文件而打开文件|
|`ios::ate`|初始位置：文件尾|
|`ios::app`|追加方式写文件|
|`ios::trunc`|如果文件存在先删除，再创建|
|`ios::binary`|二进制方式|

> **注意**：文件打开方式可以配合使用，利用 `|` 操作符。
> 
> **例如**：用二进制方式写文件
> 
> cpp
> 
> 运行
> 
> ```
> ios::binary | ios::out
> ```
