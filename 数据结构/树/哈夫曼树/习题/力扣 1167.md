# LeetCode 1167. 连接木棍的最低费用（Minimum Cost to Connect Sticks）

## 题目描述

为了装修新房，你需要加工一些长度为正整数的棒材 `sticks`。

如果要将长度分别为 `X` 和 `Y` 的两根棒材连接在一起，你需要支付 `X + Y` 的费用。由于施工需要，你必须将所有棒材连接成一根。

返回你把所有棒材连接成一根时所需的**最低总费用**。

---

### 示例 1：

- 输入：`sticks = [2,4,3]`
- 输出：`14`
- 解释：
    
    1. 先合并 2 和 3，费用为 `2 + 3 = 5`，此时剩余棒材为 `[4, 5]`。
    2. 再合并 4 和 5，费用为 `4 + 5 = 9`。
    3. 总费用：`5 + 9 = 14`。
    

### 示例 2：

- 输入：`sticks = [1,8,3,5]`
- 输出：`30`

### 提示：

- `1 <= sticks.length <= 10^4`
- `1 <= sticks[i] <= 10^4`

---

## 核心思路

这是一道典型的**哈夫曼树模型**问题，贪心策略的核心是：**每次合并当前长度最小的两根木棍**，这样可以让小长度的木棍被重复计算的次数最少，从而降低总费用。

实现时可以用 ** 最小堆（优先队列）** 来高效获取和更新当前最小的两个元素。

---

## 代码示例（C++）

cpp

运行

```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int connectSticks(vector<int>& sticks) {
        if (sticks.size() <= 1) return 0;
        
        // 构建最小堆
        priority_queue<int, vector<int>, greater<int>> minHeap(sticks.begin(), sticks.end());
        int totalCost = 0;
        
        while (minHeap.size() > 1) {
            // 取出两个最小的木棍
            int first = minHeap.top(); minHeap.pop();
            int second = minHeap.top(); minHeap.pop();
            
            // 合并并计算费用
            int cost = first + second;
            totalCost += cost;
            
            // 将合并后的木棍放回堆中
            minHeap.push(cost);
        }
        
        return totalCost;
    }
};
```

---

## 复杂度分析

- 时间复杂度：`O(n log n)`，其中 `n` 是木棍数量。构建堆的时间为 `O(n)`，每次取堆顶、合并、入堆的操作均为 `O(log n)`，共需 `n-1` 次合并操作。
- 空间复杂度：`O(n)`，用于存储最小堆。
