# 图的邻接表表示法笔记

---

## 一、核心定义

邻接表是图的一种链式存储结构，适合表示**稀疏图**，核心结构如下：

- 主体为一个**数组 / 向量** `v[1..n]`，数组的每个元素对应图中的一个顶点。
- 每个 `v[i]` 包含两部分：
    
    1. 顶点自身的数据（如顶点编号、名称等）。
    2. 一个链表（邻接链表），存储所有**邻接于顶点`i`的顶点编号**（即从顶点`i`出发可直接到达的顶点）。
    

---

## 二、数据结构定义（伪代码）

### 1. 顶点结构体（`struct Vectic`）

cpp

运行

```
struct Vectic {
    string data_;        // 顶点的数据（如名称、编号）
    list<Node> adjList_; // 邻接链表，存储所有出边
    // 也可简化为：int data; list<int> adjList;
};
```

### 2. 边表节点结构体（`struct Node`）

cpp

运行

```
struct Node {
    int vex_;    // 邻接的顶点编号
    int weight_; // 边的权重（带权图使用，无权图可省略）
    Node* nextarc; // 指向下一个边节点的指针
};
```

## 三、关键特性与注意事项

### 1. 出度与入度

- **出度**：邻接表天然支持快速计算出度，顶点`i`的出度就是其邻接链表的长度。
- **入度**：邻接表不直接支持入度查询，若需获取顶点的入度，有两种方式：
    
    1. 遍历整个邻接表，统计所有链表中指向该顶点的节点数量。
    2. 额外构建**逆邻接表**（专门存储每个顶点的入边信息）。
    

### 2. 无向图的邻接表特点

对于无向图，每条边 `(u, v)` 会同时出现在 `u` 的邻接链表和 `v` 的邻接链表中，因此无向图的邻接表会占用 `2*E` 的空间（`E` 为边数）。

---

## 四、优缺点对比

表格

|优点|缺点|
|---|---|
|空间利用率高，仅需 `O(V+E)` 空间，适合稀疏图|查询两点间是否存在边时，需遍历链表，时间复杂度为 `O(出度)`|
|快速获取顶点的出度，遍历邻接点效率高|不直接支持入度查询，需额外遍历或构建逆邻接表|
|支持动态添加 / 删除边（链表操作灵活）|无法像邻接矩阵一样直接随机访问边|
