这道题本质是 **k 进制哈夫曼树** 的经典应用，是你之前写的 2 进制哈夫曼编码的**扩展版本**。

---

## 一、核心联系：哈夫曼树与前缀编码

题目要求的「任意编码 \(s_i\) 不是其他 \(s_j\) 的前缀」，和 2 进制哈夫曼编码的「无前缀性质」完全一致：

- 2 进制哈夫曼树：每个叶子节点对应一个编码，路径上的 `0/1` 组成编码，天然满足无前缀。
- 本题 k 进制：每个叶子节点对应一个 k 进制编码，路径上的 \(0\sim k-1\) 组成编码，同样天然满足无前缀。

而题目目标「让总长度 \(\sum w_i \times len(s_i)\) 最小」，就是哈夫曼树的核心目标 ——**带权路径长度（WPL）最小**。

---

## 二、从 2 进制到 k 进制的关键区别

### 1. 合并规则的变化

- 2 进制哈夫曼树：每次合并 **2 个权值最小的节点**，最终形成一棵二叉树。
- k 进制哈夫曼树：每次合并 **k 个权值最小的节点**，最终形成一棵 k 叉树。

### 2. 关键补全：虚拟节点

为了让合并能顺利进行，需要保证初始节点数 n 满足：

\((n-1) \mod (k-1) = 0\)

如果不满足，就需要在前面补上 \((k-1)-(n-1)\%(k-1)\) 个权值为 0 的虚拟节点，否则最后一轮合并时节点数不足 k 个，会导致树的结构不完整，无法得到最优 WPL。

---

## 三、题目两个输出的含义

### 1. 第一行：最短总长度

就是 k 进制哈夫曼树的 **带权路径长度（WPL）**，计算方式：

\(WPL = \sum w_i \times len(s_i)\)

和 2 进制哈夫曼编码的 WPL 完全一致，只是合并规则不同。

### 2. 第二行：最长编码的最短长度

在保证 WPL 最小的前提下，我们需要让最长的编码尽可能短。实现方式是：

- 合并时优先选择权值小的节点，同时**优先选择深度小的节点**合并，避免让某些节点的路径过长。
- 实现时可以在优先队列里存 pair `(权值, 深度)`，当权值相同时，优先合并深度小的节点，这样能让树的高度尽可能平衡，从而让最长编码的长度最小。

## 四、和你之前写的 2 进制哈夫曼编码的对比

表格

|对比项|2 进制哈夫曼编码|本题 k 进制哈夫曼树|
|---|---|---|
|合并节点数|每次合并 2 个|每次合并 k 个|
|初始节点数|无需补全|需补虚拟节点满足 \((n-1)\mod(k-1)=0\)|
|目标 1|WPL 最小|WPL 最小（总长度最短）|
|目标 2|无额外要求|树高最小（最长编码最短）|
|优先队列元素|`(权值)`|`(权值, 深度)`|

## 五、核心思路代码（和你之前的写法一脉相承）

cpp

运行

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;
using ll = long long;

struct Node {
    ll w; // 权值
    ll dep; // 深度，用来求最长编码长度
    Node(ll w_, ll dep_) : w(w_), dep(dep_) {}
    bool operator>(const Node& other) const {
        if (w != other.w) return w > other.w; // 权值小的优先
        return dep > other.dep; // 权值相同，深度小的优先，让树更平衡
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    priority_queue<Node, vector<Node>, greater<Node>> q;
    for (int i = 0; i < n; ++i) {
        ll w;
        cin >> w;
        q.emplace(w, 0);
    }

    // 补虚拟节点
    if (k > 2) {
        int add = (k - 1) - (n - 1) % (k - 1);
        for (int i = 0; i < add; ++i) {
            q.emplace(0, 0);
        }
    }

    ll total = 0;  //WPL
    ll max_len = 0;  //最大深度
    while (q.size() > 1) {
        ll sum_w = 0;
        ll max_dep = 0;
        // 合并 k 个节点
        for (int i = 0; i < k; ++i) {
            Node cur = q.top(); q.pop();
            sum_w += cur.w;
            max_dep = max(max_dep, cur.dep);
        }
        total += sum_w; // 每次合并的权值和，就是WPL的累加
        ll new_dep = max_dep + 1;
        max_len = max(max_len, new_dep);
        q.emplace(sum_w, new_dep);
    }

    cout << total << "\n" << max_len << "\n";
    return 0;
}
```
