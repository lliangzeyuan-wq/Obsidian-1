```
    ├── messages.html   # 消息列表页

```

## 📄 各模块功能说明

### 1. 公共资源层

表格

|文件|作用|
|---|---|
|`css/style.css`|全局样式变量、基础重置、按钮 / 卡片 / 输入框等通用组件样式，保证所有页面风格统一|
|`js/api.js`|统一封装所有后端接口请求（登录、匹配、聊天、用户信息等），避免重复代码|
|`js/utils.js`|通用工具函数：登录校验 `checkLogin()`、提示框 `showToast()`、时间格式化、本地存储操作等|

### 2. 业务页面层

表格

|页面|功能|核心流程|
|---|---|---|
|`index.html`|用户登录 / 注册|账号验证 → 登录状态写入本地存储 → 跳转到 `purpose.html`|
|`purpose.html`|选择交友目的|选择搭子类型（学习 / 考研 / 交友 / 恋爱）→ 保存到本地存储 → 跳转到资料完善 / 匹配页|
|`profile-edit.html`|完善个人资料|分步填写基础信息、学习偏好、兴趣标签 → 提交到后端 → 标记资料已完成|
|`home.html`|首页|展示推荐动态 / 公告 / 功能入口 → 导航到其他页面|
|`match.html`|智能匹配|根据交友目的和筛选条件加载匹配用户 → 查看资料 / 发起邀请|
|`invites.html`|交友邀请管理|收到的邀请列表 → 同意 / 拒绝邀请|
|`messages.html`|消息列表|聊天列表 / 系统通知 → 点击进入聊天页|
|`chat.html`|一对一聊天|加载聊天记录 → 发送 / 接收消息|
|`profile.html`|个人中心|查看 / 编辑资料、查看好友、切换交友目的、退出登录|

## 🧩 架构特点说明（答辩 / 论文可用）

1. **分层清晰**：公共资源层（CSS/JS）与业务页面层分离，降低耦合度，便于维护和扩展。
2. **统一封装**：
    
    - 所有接口请求都在 `api.js` 中统一管理，后续修改接口地址或请求方式时，无需修改所有页面。
    - 通用工具函数（如登录校验、提示）封装在 `utils.js` 中，所有页面可直接复用。
    
3. **风格统一**：所有页面共用 `style.css` 中的样式变量和组件，保证了整体视觉风格的一致性。
4. **状态管理**：使用 `localStorage` 存储登录状态、当前交友目的等信息，实现页面间的状态传递。
