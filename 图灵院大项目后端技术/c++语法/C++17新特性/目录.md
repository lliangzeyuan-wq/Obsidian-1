
# C++17 后端开发必掌握特性（只列项目高频用到，不记冷门）

## 一、语法简化（天天写代码都用）

1. **结构化绑定 `auto [a,b] = pair/map`** 读取数据库返回、map 查询、结构体、tuple 必备
    
    ```
    std::map<long,std::string> user;
    for(auto [id,name] : user) {}
    ```
    
2. **类模板参数推导 CTAD** 不用手写模板参数，简化智能指针、容器创建
    
    ```
    std::vector vec{1,2,3}; // 不用 vector<int>
    std::shared_ptr p = std::make_shared<User>();
    ```
    
3. **if/switch 初始化语句** 减少作用域污染，数据库查询、资源判断高频
    
    ```
    if(auto res = db->query(sql); res.ok()) {}
    ```
    
4. **inline 内联变量** 头文件全局常量、全局配置单例，解决多重定义报错（项目配置、常量枚举必用）

## 二、类型 & 编译期（性能、框架底层核心）

1. **`constexpr if` 编译期分支** Oatpp、模板工具库大量使用，根据类型在编译期丢弃无效代码，无运行开销
2. **折叠表达式（可变参数模板）** 封装日志工具、批量 SQL 拼接、多参数工具函数必备
    
    ```
    template<typename... Args>
    void print(Args&&... args) {
        (std::cout << ... << args);
    }
    ```
    
3. **`std::void_t` 类型检测** 写通用工具、判断结构体是否存在某个成员（通用序列化工具、JSON 解析）
4. **`std::is_aggregate`、类型萃取增强** 反射简易实现，yaml/json 序列化依赖

## 三、STL 新增容器 / 工具（业务高频）

1. **`std::optional<T>` 可选值** 数据库字段可为 NULL、接口可选参数，替代魔数标记空值
    
    ```
    std::optional<std::string> getNick();
    if(auto name = getNick(); name.has_value())
    ```
    
2. **`std::any` 任意类型存储** 通用配置容器、通用接口参数（类似 void * 但安全）
3. **`std::variant<Ts...>` 多类型联合体** 接口多类型返回、多类型配置，替代不安全 union
4. **`std::filesystem` 文件系统库** FastDFS 本地文件操作、日志文件管理、Excel/PDF 文件读写，不用调用 C 语言文件 API
5. **`std::string_view` 字符串视图** 零拷贝读取字符串，SQL 拼接、日志、接口参数解析，大幅减少内存拷贝（后端性能关键点）

## 四、并发 / 内存（后端多线程核心）

1. **`std::shared_mutex` 读写锁** 缓存、全局配置、共享数据：读多写少场景，比 mutex 性能高很多（Redis 缓存、全局配置必用）
2. **内存对齐新特性 `align_val_t`** 高性能内存池、网络缓冲区优化

## 五、实用小特性（避坑、简化代码）

1. **删除重复命名空间嵌套 `namespace A::B::C`**
2. **`[[nodiscard]]` 标记返回值** 数据库操作、函数返回错误码，忘记接收返回值编译器警告，减少线上 bug
    
    ```
    [[nodiscard]] DBResult query(std::string sql);
    ```
    
3. **`[[fallthrough]]` switch 穿透标记**
4. **十六进制浮点数、数字分隔符 `1'000'000`**
5. **lambda 捕获 `*this` 拷贝当前对象（异步线程避免野指针）**
    
    ```
    [*this](){ // 拷贝一份对象，线程结束不影响外部
    }
    ```
    

# 后端项目**完全不用学**的冷门特性（节省时间）

1. 并行算法 std::execution（后端极少用）
2. 结构化异常处理
3. 动态内存分配重载高级用法
4. 浮点常量新格式

# 学习优先级（按你项目使用频率排序）

1. string_view、optional、variant、结构化绑定（写业务天天用）
2. if 初始化、[[nodiscard]]、lambda *this、CTAD（简化代码、防 bug）
3. shared_mutex（缓存多线程必备）
4. std::filesystem（文件操作）
5. constexpr if、折叠表达式（封装工具类、框架代码）
6. inline 变量、void_t（底层通用工具）

## 配套练习建议
