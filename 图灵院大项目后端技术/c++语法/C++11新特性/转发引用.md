
# 一、转发引用（万能引用）核心定义

**转发引用 = `T&&`（模板参数） / `auto&&`** 只有两种写法属于转发引用：

1. 模板函数形参：`template<class T> void func(T&& x)`
2. `auto&& var = xxx;`

注意：**普通类型 `int&&` 不是转发引用，只是单纯右值引用！**

```
int a = 10;
int&& r = a; // 报错，普通右值引用不能绑左值

template<class T>
void func(T&& x) { /* 转发引用，既能绑左值也能绑右值 */ }
auto&& r2 = a; // 转发引用，合法
```

## 二、推导规则（核心）

当右侧是**左值**：`T` 推导为 `T&`，最终类型折叠为 `T& && → T&`（普通左值引用） 当右侧是**右值**：`T` 推导为 `T`，最终类型是 `T&&`（右值引用）

引用折叠规则（必须记住）：

1. `& + & → &`
2. `& + && → &`
3. `&& + & → &`
4. `&& + && → &&`

### 示例 1：模板 T&& 推导

```
template<class T>
void func(T&& x) {}

int val = 10;
func(val);  // val是左值 → T = int& → T&& = int& && = int&
func(20);   // 20是右值 → T = int → T&& = int&&
```

### 示例 2：auto&& 推导（结构化绑定用到的）

```
int val = 10;
auto&& r1 = val;  // val左值 → auto = int& → r1:int&
auto&& r2 = 20;   // 20右值 → auto = int  → r2:int&&
```
