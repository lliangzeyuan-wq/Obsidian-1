
先把规则说死，再套到 `mt-5`、`my-3` 上，你就一下看懂了。

---

## 一、Bootstrap 间距类的固定公式

格式：

plaintext

```
{m/p}{方向}-{数字}
```

- **m** = margin（外边距，元素外面的距离）
- **p** = padding（内边距，元素里面的距离）

方向：

- **t** = top（上）
- **b** = bottom（下）
- **l** = left（左）
- **r** = right（右）
- **x** = left+right（左右一起）
- **y** = top+bottom（上下一起）

数字（0–5，对应 rem）：

- 0：0rem
- 1：0.25rem
- 2：0.5rem
- 3：1rem
- 4：1.5rem
- 5：3rem

---

## 二、mt-5 拆解

plaintext

```
mt-5
```

- **m** = margin（外边距）
- **t** = top（顶部）
- **5** = 3rem

翻译：

plaintext

```
.mt-5 {
  margin-top: 3rem;
}
```

作用：**给这个元素的顶部，外面加 3rem 的距离**（离上面的元素远一点）。

---

## 三、my-3 拆解

plaintext

```
my-3
```

- **m** = margin（外边距）
- **y** = top+bottom（上下）
- **3** = 1rem

翻译：

plaintext

```
.my-3 {
  margin-top: 1rem;
  margin-bottom: 1rem;
}
```

作用：**给这个元素的顶部和底部，外面各加 1rem 的距离**（上下都拉开一点）。

---

## 四、放到你之前的代码里看

html

预览

```
<div class="container mt-5">
```

→ 容器**顶部外边距 3rem**，页面顶部不会贴着浏览器边。

html

预览

```
<div class="row my-3">
```

→ 这一行**上下外边距各 1rem**，和上面标题、下面内容都有间距，不挤在一起。

---

## 五、一句话总结

- **mt-5**：**上边距很大（3rem）**
- **my-3**：**上下边距中等（各 1rem）**
