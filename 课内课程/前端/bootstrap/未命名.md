

# Bootstrap 排版类对照表（翻译 + 说明）

---

## 第一部分：核心排版类

表格

|类名|英文描述|中文翻译|补充说明|
|:--|:--|:--|:--|
|`.blockquote`|Styles quoted blocks of content from another source (adds a larger font-size (1.25rem))|为来自其他来源的引用内容设置样式（增大字体大小为 1.25rem）|用于引用大段文字，自带缩进和字号放大效果|
|`.blockquote-footer`|Styles the source title inside the blockquote (light grey text with indentation)|为引用块内的来源标题设置样式（浅灰色文本 + 缩进）|引用来源的专用样式，常放在`<footer>`标签内|
|`.font-italic`|Italic text|斜体文本|让文字变为斜体|
|`.font-weight-bold`|Bold text|加粗文本|字体加粗，等效于`font-weight: bold`|
|`.font-weight-bolder`|Bolder text (font-weight: bolder)|更粗的文本（`font-weight: bolder`）|比`bold`更粗的字重|
|`.font-weight-light`|Light weight text (font-weight:300)|轻量文本（`font-weight:300`）|字体更细，字重为 300|
|`.font-weight-lighter`|Lighter weight text (font-weight:lighter)|更轻量的文本（`font-weight:lighter`）|比`light`更细，继承父元素的更轻字重|
|`.font-weight-normal`|Normal text (font-weight:400)|常规文本（`font-weight:400`）|恢复默认字重，常用于取消加粗|
|`.h1 - .h6`|Makes an element look like a heading of the chosen class (h1-h6)|使元素呈现所选标题类（h1-h6）的样式|让普通文本拥有标题的字号和样式|

## 第二部分：更多排版类

表格

|类名|英文描述|中文翻译|补充说明|
|:--|:--|:--|:--|
|`.initialism`|Displays the text inside an `<abbr>` element in a slightly smaller font size|让`<abbr>`标签内的文本字号稍小|配合`<abbr>`缩写标签使用，让缩写词更紧凑|
|`.lead`|Increase the font size and line height of a paragraph|增大段落的字体大小和行高|用于文章开头的引导段落，突出正文内容|
|`.list-inline`|Places all list items on a single line (used together with `.list-inline-item` on each `<li>` elements)|将所有列表项放在同一行（需配合每个`<li>`上的`.list-inline-item`使用）|实现水平排列的列表，常用于导航、标签组|
|`.list-inline-item`|Places all list items on a single line (used together with `.list-inline` on the parent `<ul>` element)|将列表项放在同一行（需配合父元素`<ul>`上的`.list-inline`使用）|`.list-inline`的配套类，控制单个列表项的内联样式|
|`.list-unstyled`|Removes all default list-style (bullets, left margin, etc.) styling from a `<ul>` or `<ol>` list|移除`<ul>`或`<ol>`列表的所有默认样式（项目符号、左外边距等）|让列表变成无符号的普通文本，常用于自定义列表|
|`.mark`|Highlights text: Highlighted text|高亮文本：高亮显示文本|给文本添加背景高亮效果，类似荧光笔标记|
|`.small`|Creates a lighter, secondary text in any heading|在任意标题中创建更浅的次要文本|用于标题内的补充说明文字，字号更小、颜色更淡|
|`.text-*-center`|Center-aligns text on different screens|在不同屏幕尺寸上让文本居中对齐|响应式居中对齐，`*`代表屏幕断点（如`sm`/`md`/`lg`）|
|`.text-*-left`|Left-aligns text on different screens|在不同屏幕尺寸上让文本左对齐|响应式左对齐|
|`.text-*-right`|Right-aligns text on different screens|在不同屏幕尺寸上让文本右对齐|响应式右对齐|
|`.text-break`|Prevents long text from breaking layout|防止长文本破坏页面布局|强制长单词 / URL 换行，避免撑破容器|
|`.text-capitalize`|Indicates capitalized text|文本首字母大写|每个单词的首字母转为大写|
|`.text-center`|Center-aligns text|文本居中对齐|非响应式的居中对齐|
|`.text-dark`|Dark grey text color|深灰色文本|深色文本，适合浅色背景|
|`.text-decoration-none`|Removes the underline from a link|移除链接的下划线|让链接看起来像普通文本，常用于导航链接|
|`.text-hide`|Hides text (helps replace an element's text content with a background image)|隐藏文本（用于用背景图片替代元素文本内容）|隐藏文字但保留元素位置，适合用图片替代文字|
|`.text-justify`|Indicates justified text|文本两端对齐|让文本在容器内左右两端都对齐|
|`.text-left`|Aligns the text to the left|文本左对齐|非响应式的左对齐|
|`.text-lowercase`|Changes text to lowercase|文本转为全小写|所有字母转为小写|
|`.text-nowrap`|Prevents the text from wrapping|禁止文本换行|强制文本在一行显示，超出部分会溢出|
|`.text-reset`|Resets the color of a text or a link (inherits the color from its parent)|重置文本或链接的颜色（继承父元素颜色）|让链接恢复普通文本颜色，取消默认蓝色|
|`.text-right`|Aligns text to the right|文本右对齐|非响应式的右对齐|
|`.text-uppercase`|Makes text uppercase|文本转为全大写|所有字母转为大写|
