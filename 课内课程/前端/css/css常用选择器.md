

你上传的这张图片展示的是 CSS 中非常核心的**组合选择器**（也叫复合选择器）。初学者在分不清“后代、子代、兄弟”的时候很容易写错样式。

为了让你彻底搞懂，我们先构建一个**标准 HTML 家族树（DOM 树）代码**，然后把图片中的 5 种选择器一个一个放进去“抓人”，看看它们分别能精准抓到谁。

### 🧱 基础 HTML 结构（用于测试的例子）

假设我们的网页上有这样一段看似复杂的 HTML 结构：

HTML

```
<div>
  <p>我是 div 的【亲儿子】 1</p> 
  
  <section>
    <p>我是 div 的【亲孙子】（section 的亲儿子）</p> 
  </section>
  
  <p>我是 div 的【亲儿子】 2</p> 
</div>

<p>我是紧跟在 div 后面的【亲弟弟】</p> 
<p>我是排在后面的【亲弟弟/妹妹】 2</p>
<p>我是排在后面的【亲弟弟/妹妹】 3</p>
```

## 4. 后代选择器 (`div p`)

- **逻辑：** 只要 `<p>` 标签包裹在 `<div>` 的**内部**（不管它是儿子、孙子、重孙子……），全部选中。中间用**空格**分隔。
    
- **执行命令：** “把 `div` 家里**所有子子孙孙**的 `<p>` 标签都变成红色！”
    

CSS

```
div p {
  color: red;
}
```

- **被选中的幸运儿：**
    
    - `我是 div 的【亲儿子】 1`
        
    - `我是 div 的【亲孙子】`
        
    - `我是 div 的【亲儿子】 2`
        

## 5. 子代选择器 (`div > p`)

- **逻辑：** 只有直接被 `<div>` 包裹的**第一层** `<p>` 标签（也就是**亲儿子**）才会被选中。孙子辈及以下直接忽略。中间用 **`>`** 分隔。
    
- **执行命令：** “只把 `div` 的**亲生儿子** `<p>` 变成绿色，孙子不准管！”
    

CSS

```
div > p {
  color: green;
}
```

- **被选中的幸运儿：**
    
    - `我是 div 的【亲儿子】 1`
        
    - `我是 div 的【亲儿子】 2` _(那个【亲孙子】因为外面隔了一层 `<section>`，所以逃过一劫)_
        

## 6. 相邻兄弟选择器 (`div + p`)

- **逻辑：** 必须满足两个条件：① 它是 `<div>` 的**平辈（兄弟）**；② 它**紧跟**在 `<div>` 的后面（挨得最近的亲弟弟）。中间用 **`+`** 分隔。
    
- **执行命令：** “把住在 `div` 家**隔壁、紧挨着**的那个弟弟 `<p>` 变成蓝色！”
    

CSS

```
div + p {
  color: blue;
}
```

- **被选中的幸运儿：**
    
    - `我是紧跟在 div 后面的【亲弟弟】` _(只有这一个会被染成蓝色，再后面的弟弟妹妹它就不管了)_
        

## 7. 通用兄弟选择器 (`div ~ p`)

- **逻辑：** 只要是跟 `<div>` 同辈的、并且在 `<div>` **之后**的所有 `<p>` 标签（所有的弟弟妹妹），全部选中。中间用 **`~`** 分隔。
    
- **执行命令：** “把 `div` 后面**所有的**弟弟妹妹 `<p>` 全都变成紫色！”
    

CSS

```
div ~ p {
  color: purple;
}
```

- **被选中的幸运儿：**
    
    - `我是紧跟在 div 后面的【亲弟弟】`
        
    - `我是排在后面的【亲弟弟/妹妹】 2`
        
    - `我是排在后面的【亲弟弟/妹妹】 3`
        

## 8. 选择器分组 (`h1, p`)

- **逻辑：** 这个其实不属于上述的“家族关系”，而是一种**偷懒/集体打包**的写法。用**逗号 `,`** 分隔开不同的标签，表示它们共同拥有一套样式。
    
- **执行命令：** “不管你们什么关系，请全网所有的 `<h1>` 和 `<p>` 标签，通通把字体加粗！”
    

CSS

```
h1, p {
  font-weight: bold;
}
```

- **实际效果：** 相当于你分别写了 `h1 { font-weight: bold; }` 和 `p { font-weight: bold; }`，用逗号合起来写能让代码少写好几行。
    

### 💡 快速记忆口诀

- **空格（`A B`）：** 只要是后代，统统抓起来。
    
- **大于号（`A > B`）：** 只要亲儿子，孙子靠边站。
    
- **加号（`A + B`）：** 紧跟在身后，只抓大弟弟。
    
- **波浪号（`A ~ B`）：** 身后所有弟，一个都不放。
    
- **逗号（`A, B`）：** 大家排排坐，全都有果吃。
