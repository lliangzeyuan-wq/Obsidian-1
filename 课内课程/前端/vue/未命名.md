

# Vue 回车按键修饰符案例笔记

## 一、页面 index.html

html

预览

```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Vue.js Event Handling</title>
    <!--引入vue开发版-->
    <script src="https://cdn.jsdelivr.net/npm/vue@2.7.0/dist/vue.js"></script>
</head>
<body>
    <div id="key_1">
        <!--keyup.enter：回车抬起触发方法；v-bind:style绑定样式对象-->
        <input type="text" v-on:keyup.enter="showinputvalue" v-bind:style="styleobj" placeholder="Type your name here.."/>
        <!--插值表达式，渲染name数据-->
        <h3> {{name}}</h3>
    </div>
    <script src="index.js"></script>
</body>
</html>
```

### HTML 知识点

1. `v-on:keyup.enter`：**按键修饰符**，输入框按下回车松开后执行`showinputvalue`函数，简写`@keyup.enter`
2. `v-bind:style="styleobj"`：动态绑定 css 样式，简写`:style="styleobj"`，样式数据写在 Vue 的 data 中
3. `placeholder`：输入框灰色默认提示文字
4. `{{name}}`：插值语法，读取 data 里 name 的值渲染页面

## 二、逻辑 index.js

js

```
var vm = new Vue({
    el: '#key_1', // 挂载到id=key_1的div
    data: {
        name: '', // 存放输入框内容
        styleobj: { // input样式对象
            width: "100%",
            padding: "12px 20px",
            margin: "8px 0",
            boxSizing: "border-box"
        }
    },
    methods: { // 存放事件函数
        showinputvalue: function (event) {
            // event.target=触发事件的input；.value获取输入框填写内容
            this.name = event.target.value;
        }
    }
});
```

### JS 知识点

1. `el:'#key_1'`：Vue 管控 id 为 key_1 的区域
2. `data{}`：存放所有页面需要的数据（数据、样式）
3. `methods{}`：专门存放事件触发的自定义函数
4. `event`：事件自带参数（事件对象）
    
    - `event.target`：**触发当前事件的 DOM（本案例就是 input 输入框）**
    - `event.target.value`：拿到输入框内用户输入的文本
    
5. `this.name`：this 代表当前 Vue 实例，给 data 中的 name 赋值

## 三、整体运行流程

1. 在 input 输入文字
2. **按下回车键松开 → keyup.enter 触发 showinputvalue 函数**
3. 函数通过`event.target.value`取出输入内容，赋值给`this.name`
4. name 数据发生变化 → 页面`{{name}}`自动刷新展示文字

## 四、本课新单词 & 修饰符

### 常用按键修饰符（keyup.xxx）

.enter 回车 | .space 空格 | .delete 删除 / 退格 | .esc 退出 | .up/.down/.left/.right 方向键

### 指令简写

`v-on:xxx` → `@xxx`、`v-bind:style` → `:style`
