

| 按键修饰符   | 对应按键                              |
| ------- | --------------------------------- |
| .enter  | 回车键                               |
| .space  | 空格键                               |
| .esc    | 退出键                               |
| .delete | Delete 删除键、Backspace 退格键（两个按键都生效） |
| .up     | 向上方向键                             |
| .down   | 向下方向键                             |
| .left   | 向左方向键                             |
| .right  | 向右方向键                             |
| .tab    | Tab 切换键                           |
