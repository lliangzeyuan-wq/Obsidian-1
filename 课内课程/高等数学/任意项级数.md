
#  条件收敛与绝对收敛

## 任意项级数 条件收敛 & 绝对收敛 完整笔记、

## 一、两个核心定义

设任意项级数 sum (n=1→∞) uₙ （项可正、可负、可 0）

### 1. 绝对收敛

若绝对值构成的正项级数 sum (n=1→∞)|uₙ| 收敛，则称 sum uₙ 绝对收敛，且原级数一定收敛：

sum (n=1→∞)|uₙ| 收敛 ⇒ sum (n=1→∞) uₙ 收敛（绝对收敛）

### 2. 条件收敛

若绝对值级数 sum (n=1→∞)|uₙ| 发散，但原级数 sum (n=1→∞) uₙ 本身收敛，则称 sum uₙ 条件收敛：

sum (n=1→∞)|uₙ| 发散，sum (n=1→∞) uₙ 收敛 ⇒ 条件收敛

## 二、核心本质区别（为什么要区分）

1. 绝对收敛级数：任意交换项的顺序、任意加括号，级数依然收敛，且总和不变，性质稳定。
2. 条件收敛级数：一旦改变项的先后顺序，级数的敛散性、总和都会改变（黎曼重排定理：重排后可以收敛到任意实数，甚至发散到正负无穷），性质极不稳定。

## 三、两大重要性质

### 性质 1

sum (n=1→∞)|uₙ| 收敛 ⇒ sum (n=1→∞) uₙ 收敛

翻译：绝对值收敛 → 原级数必收敛。

做题技巧：判断任意项级数收敛，优先判绝对值级数，直接用正项级数判别法（比值 / 根值 / 比较），简化计算。

### 性质 2（逆否命题，考试高频）

sum (n=1→∞) uₙ 发散 ⇒ sum (n=1→∞)|uₙ| 发散

等价逻辑：如果原级数发散，绝对值级数一定发散。

### 重点推论（考试五星考点）

如果用**比值判别法 / 根值判别法**算出 sum|uₙ| 发散，则原级数 sum uₙ 一定发散。

补充区分：

- 普通比较判别法推出 sum|uₙ| 发散：不能判定原级数发散（原级数可能条件收敛）
- 比值 / 根值判别法推出 sum|uₙ| 发散：直接断定原级数发散

## 四、两个级数加减后的敛散性规律

设 sum uₙ、sum vₙ 为两个级数，研究 sum (uₙ ± vₙ) 的收敛类型

1. sum uₙ 绝对收敛 + sum vₙ 绝对收敛 → sum (uₙ±vₙ) 绝对收敛
2. sum uₙ 绝对收敛 + sum vₙ 条件收敛 → sum (uₙ±vₙ) 条件收敛（必考结论）
3. sum uₙ 条件收敛 + sum vₙ 条件收敛 → 类型不确定，需要单独判别

简单证明（一绝对一条件）：

假设 sum uₙ 绝对收敛，sum vₙ 条件收敛。

反证：若 sum (uₙ+vₙ) 绝对收敛，则 sum|(uₙ+vₙ)-uₙ| = sum|vₙ| 绝对收敛，与 sum vₙ 条件收敛矛盾。

因此 sum (uₙ+vₙ) 只能是条件收敛。

## 五、完整做题判别流程

1. 第一步：构造绝对值级数 sum|uₙ|，使用正项级数判别法判断敛散性
    
    - 若 sum|uₙ| 收敛 → 级数**绝对收敛**，判断结束；
    - 若用比值 / 根值法推出 sum|uₙ| 发散 → 原级数**发散**，判断结束；
    
2. 若仅通过比较法推出 sum|uₙ| 发散：
    
    单独判断原级数 sum uₙ：
    
    - 原级数收敛 → **条件收敛**；
    - 原级数发散 → 整体级数发散。
    

## 六、典型例题区分

### 例 1 绝对收敛

sum (n=1→∞) [(-1)ⁿ /n²]

|uₙ| = 1/n²，p=2>1 的 p 级数收敛 → 绝对收敛

### 例 2 条件收敛

sum (n=1→∞) [(-1)^(n+1) /n]

|uₙ| = 1/n 调和级数发散，原交错级数通过莱布尼茨判别法收敛 → 条件收敛

### 例 3 直接发散

sum (n=1→∞) [(-1)ⁿ・2ⁿ /n]

比值判别法：lim |u_{n+1}/uₙ| = 2 > 1，绝对值级数发散 → 原级数直接发散
