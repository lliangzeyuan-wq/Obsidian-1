# 交错级数 莱布尼茨判别法（适配 Obsidian 纯文本版）

## 一、交错级数标准形式

交错级数：\(\sum_{n=1}^∞ (-1)^n u_n\)，要求 \(u_n > 0\)（每一项的绝对值都是正数，正负交替出现）

## 二、莱布尼茨判别法（两个条件同时满足，级数一定收敛）

两个充要条件：

1. 数列单调递减：\(u_n ≥ u_{n+1}\) 对所有 \(n≥1\) 成立
2. 通项极限趋于 0：\(\lim_{n \to ∞} u_n = 0\)

满足两条 → 该交错级数**收敛**。

## 三、完整判断流程（先判收敛，再区分绝对 / 条件收敛）

1. 先用莱布尼茨判别法，判断交错级数 \(\sum (-1)^n u_n\) 是否收敛；
2. 再构造绝对值正项级数 \(\sum_{n=1}^∞ |(-1)^n u_n| = \sum u_n\)，用正项级数判别法判断：
    
    - 若 \(\sum u_n\) 收敛 → 原交错级数**绝对收敛**
    - 若 \(\sum u_n\) 发散 → 原交错级数**条件收敛**
    

## 四、关键易错点（橙色手写重点）

1. 莱布尼茨判别法**只能用来判定收敛，不能判定发散**
2. 如果级数不满足莱布尼茨两个条件，**不能直接说级数发散**，需要换别的判别方法重新判断。

## 五、四种判断 \(u_n ≥ u_{n+1}\)（数列单调递减）的方法

### 方法① 作差法

计算 \(u_{n+1} - u_n\)：

- 结果 \(<0\) → \(u_{n+1} < u_n\)，数列单调递减，满足条件
- 结果 \(>0\) → 单调递增，不满足

### 方法② 作商法

计算 \(\displaystyle \frac{u_{n+1}}{u_n}\)：

- 比值 \(<1\) → \(u_{n+1} < u_n\)，单调递减
- 比值 \(>1\) → 单调递增

### 方法③ 构造函数求导法（最常用，n 换成 x 求导）

把离散变量 n 换成连续自变量 x，设 \(f(x)=u_x\)，求导 \(f'(x)\)：

- \(f'(x) < 0\)：函数单调递减，对应数列 \(u_n\) 单调递减
- \(f'(x) > 0\)：函数单调递增

### 方法④ 数学归纳法

适合带阶乘、递推式的数列，证明 \(u_{n+1} < u_n\) 对全体正整数成立。

## 六、例题演示

### 例题：交错调和级数 \(\displaystyle\sum_{n=1}^∞ \frac{(-1)^{n+1}}{n}\)

\(u_n = \displaystyle\frac1n\)

1. 单调性：\(u_{n+1}=\displaystyle\frac1{n+1} < \frac1n = u_n\)，单调递减
2. 极限：\(\displaystyle\lim_{n \to ∞}\frac1n = 0\)
    
    两条全部满足 → 交错级数收敛。
    
    再判断绝对值级数 \(\displaystyle\sum \frac1n\)（调和级数）发散，因此该级数**条件收敛**。

### 反例：不满足莱布尼茨条件的级数

\(\displaystyle\sum_{n=1}^∞ \frac{(-1)^n n}{n+1}\)

\(\displaystyle\lim_{n \to ∞} u_n = \lim \frac{n}{n+1}=1≠0\)，第二条不满足，直接判定级数发散。
