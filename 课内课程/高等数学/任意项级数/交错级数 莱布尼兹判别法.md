# 交错级数 莱布尼茨判别法（Obsidian 纯文本无公式乱码版）

## 一、交错级数标准形式

交错级数：sum (n 从 1 到无穷) [(-1)^n・uₙ]

要求：uₙ > 0，每一项绝对值都是正数，正负交替出现

## 二、莱布尼茨判别法（两个条件同时满足，级数一定收敛）

两个必须同时满足的条件：

1. 数列单调递减：对所有 n≥1，都有 uₙ ≥ u_{n+1}
2. n 趋向无穷时，uₙ的极限等于 0

两条全部满足 → 该交错级数收敛

## 三、完整判断流程（区分绝对 / 条件收敛）

1. 先用莱布尼茨判别法，判断交错级数本身是否收敛；
2. 再构造绝对值级数 sum (n 从 1 到无穷) uₙ，用正项级数判别法判断：
    
    - 若 sum uₙ 收敛 → 原交错级数【绝对收敛】
    - 若 sum uₙ 发散 → 原交错级数【条件收敛】
    

## 四、核心易错考点

1. 莱布尼茨判别法**只能用来证明收敛，不能判定发散**
2. 若级数不满足两个条件，不能直接断定级数发散，需要更换其他判别法重新判断

## 五、四种判断数列单调递减 uₙ ≥ u_{n+1} 的方法

1. 作差法
    
    计算 u_{n+1} - uₙ，和 0 比较：
    
    结果＜0 → u_{n+1}＜uₙ，单调递减；结果＞0 则递增
    
2. 作商法
    
    计算 u_{n+1} /uₙ，和 1 比较：
    
    比值＜1 → 单调递减；比值＞1 则递增
    
3. 构造函数求导法（最常用）
    
    把 n 替换成连续变量 x，设 f (x)=uₓ，求导：
    
    导数＜0 → 函数单调递减，对应数列 uₙ单调递减
    
4. 数学归纳法
    
    适合带阶乘、递推表达式的数列，证明 u_{n+1} 恒小于 uₙ
    

## 六、例题

例 1 交错调和级数 sum (n=1 到∞) [(-1)^(n+1) /n]

uₙ = 1/n

① u_{n+1}=1/(n+1) ＜ 1/n = uₙ，单调递减

② n→∞时，1/n 极限为 0

满足莱布尼茨条件，交错级数收敛；

绝对值级数 sum (1/n) 是调和级数、发散，因此该级数条件收敛。

例 2 sum [(-1)^n・n/(n+1)]

n→∞时，uₙ = n/(n+1) 极限为 1，不等于 0，不满足第二条，级数直接发散。
