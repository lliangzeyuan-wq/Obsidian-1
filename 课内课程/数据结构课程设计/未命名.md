
# 10. Vue 3 与 Vue CLI

原文：Vue.js is a progressive JavaScript framework for building user interfaces. Vue 3 commonly uses components, reactivity, directives, and a virtual DOM to create efficient and maintainable web applications.

译文：Vue.js 是一款用于构建用户界面的渐进式 JavaScript 框架。Vue 3 通常借助组件、响应式系统、指令与虚拟 DOM，开发高效、易维护的网页应用。

# 网页前端开发技术 - 复习笔记

## Vue 核心特性

表格

|Vue feature（Vue 特性）|Meaning（含义）|
|---|---|
|Component-based architecture（基于组件的架构）|UI is built using reusable components with their own template, logic, and style.<br><br>页面由可复用组件搭建，每个组件拥有独立模板、业务逻辑与样式。|
|Declarative rendering（声明式渲染）|Templates describe what the UI should look like based on data.<br><br>模板依托数据，直接描述页面最终展示效果。|
|Directives（指令）|Special attributes such as v-if, v-for, v-bind, v-on, and v-model.<br><br>特殊标签属性，包含 v-if、v-for、v-bind、v-on、v-model 等。|
|Two-way data binding（双向数据绑定）|v-model keeps form input and component data synchronized.<br><br>v-model 实现表单输入框与组件数据双向同步。|
|Virtual DOM（虚拟 DOM）|Vue calculates efficient UI updates before changing the real DOM.<br><br>Vue 在操作真实页面 DOM 前，预先计算最优页面更新方案。|

## 指令 / 配置项 作用说明

表格

|Directive /option（指令 / 配置项）|Use（用途）|
|---|---|
|data()|Returns the reactive state object for each component instance. Each instance should have separate data.<br><br>为每个组件实例返回响应式数据对象，每个组件实例必须拥有独立数据。|
|`{{ }}` interpolation（插值表达式）|Displays data in the template.<br><br>在模板中渲染展示数据。|
|v-bind|Binds data to HTML attributes. Shorthand is `:`.<br><br>将数据绑定到 HTML 标签属性，简写为 `:`。|
|v-on|Handles events. Shorthand is `@`.<br><br>绑定页面事件，简写为 `@`。|
|v-model|Creates two-way binding with form controls.<br><br>给表单控件创建双向数据绑定。|
|v-for|Renders a list by iterating over an array.<br><br>遍历数组，循环渲染列表。|
|v-if|Conditionally renders an element.<br><br>根据条件判断是否渲染元素。|
|v-else / v-else-if|Alternative conditional branches.<br><br>配套 v-if 的多分支条件判断。|
|v-show|Conditionally displays an element using CSS display.<br><br>通过 CSS 的 display 属性控制元素显隐。|
|v-once|Renders an element once and then skips future updates.<br><br>元素仅渲染一次，后续数据更新不再重新渲染。|

### v-once 补充纠正说明

原文：v-once does not force re-rendering. It does the opposite: it renders the element once and then keeps it static, even if related data changes.

译文：v-once 不会触发重新渲染，作用恰好相反：元素只会渲染一次，之后保持静态，即便绑定的数据发生变化也不会更新。

## 组件注册：全局注册 / 局部注册

表格

|Registration type（注册类型）|Meaning（含义）|
|---|---|
|Global registration（全局注册）|Done with `app.component("ComponentName", Component)` in main.js. The component is available throughout the app.<br><br>在 main.js 中通过 `app.component("组件名", 组件)` 完成注册，该组件可在项目任意位置使用。|
|Local registration（局部注册）|Component is available only inside the component where it is imported and registered. It is recommended for most components to reduce naming conflicts and unnecessary global scope.<br><br>组件仅在导入并注册的父组件内可用。推荐绝大多数组件采用局部注册，减少命名冲突、避免污染全局作用域。|

## 示例：使用 v-model、插值、v-for 的 Vue 组件

vue

```
<template>
  <input v-model="name" placeholder="Enter name">
  <p>Hello {{ name }}</p>
  <ul>
    <li v-for="item in items" :key="item.id">{{ item.text }}</li>
  </ul>
</template>
```

译文：

vue

```
<template>
  <!-- 双向绑定输入框，提示文字：输入姓名 -->
  <input v-model="name" placeholder="输入姓名">
  <!-- 插值展示name数据 -->
  <p>你好 {{ name }}</p>
  <!-- 循环渲染列表 -->
  <ul>
    <li v-for="item in items" :key="item.id">{{ item.text }}</li>
  </ul>
</template>
```
