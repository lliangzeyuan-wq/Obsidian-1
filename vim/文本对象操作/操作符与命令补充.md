## 1. `gu` / `gU` / `g~`：大小写转换操作符

它们是**操作符**，可以和文本对象（`iw`/`i(`/`ap` 等）组合，实现 “对指定范围的文本做大小写操作”。

### 例子场景

假设你有一行代码：

c

运行

```
int NAME = 123;
```

- 光标在 `NAME` 上：
    
    - `guiw`：`g`+`u`（小写）+`iw`（当前单词） → `name`
    - `gUiw`：`g`+`U`（大写）+`iw`（当前单词） → `NAME`（这里本身就是大写，效果不变）
    - `g~iw`：翻转大小写 → `name`（大写变小写）
    
- 光标在括号内：
    
    c
    
    运行
    
    ```
    printf("Hello World");
    ```
    
    `gu"` 会把引号内的内容全部转成小写 → `printf("hello world");`

## 2. `J`：连接两行

作用：把**当前行和下一行**合并成一行，中间用一个空格隔开。

### 例子场景

原来的文本：

plaintext

```
Hello
World
```

光标在 `Hello` 这一行，按 `J`：

plaintext

```
Hello World
```

### 进阶用法

- `3J`：合并当前行开始的 3 行
- 配合 `:set nojoinspaces` 可以让合并时不加空格

## 3. `<Ctrl-a>` / `<Ctrl-x>`：数字增减

作用：对光标下 / 光标后的数字进行 +1 /-1，非常适合改配置、写序号。

### 例子场景

假设你有：

c

运行

```
int a = 1;
int b = 2;
int c = 3;
```

- 光标在 `1` 上，按 `<Ctrl-a>` → `int a = 2;`
- 光标在 `2` 上，按 `<Ctrl-x>` → `int b = 1;`

### 进阶用法

- `5<Ctrl-a>`：数字 +5
- `3<Ctrl-x>`：数字 -3

## 4. `g<Ctrl-A>`：创建递增序列

作用：在多行数字上生成连续的递增序列，批量改序号神器！

### 例子场景

原来的文本：

c

运行

```
int arr[4] = {
    0,
    0,
    0,
    0
};
```

操作步骤：

1. 光标移到第一个 `0` 上，按 `Ctrl-v` 进入**块选择模式**
2. 用方向键向下选中所有 4 个 `0`
3. 输入 `g<Ctrl-A>`
4. 结果自动变成：
    
    c
    
    运行
    
    ```
    int arr[4] = {
        1,
        2,
        3,
        4
    };
    ```

## 5. `<` / `>`：缩进 / 反缩进

作用：给选中的文本整体向左 / 向右缩进一个 `shiftwidth`（默认是 4 个空格），写代码格式化超常用。

### 例子场景

原来的文本（缩进混乱）：

c

运行

```
if (true) {
printf("hello");
}
```

操作步骤：

1. 光标移到 `printf` 这一行，按 `V` 进入行选择模式
2. 输入 `>` → 向右缩进，变成：
    
    c
    
    运行
    
    ```
    if (true) {
        printf("hello");
    }
    ```
    
3. 如果缩进多了，按 `<` 可以缩回去

### 进阶用法

- `3>>`：当前行 + 下面 2 行，共 3 行一起右缩进
- `<<`：当前行左缩进
- `==`：自动缩进当前行（和语言语法对齐）
