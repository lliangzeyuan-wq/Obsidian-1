## 1. `gu` / `gU` / `g~`：大小写转换操作符

它们是**操作符**，可以和文本对象（`iw`/`i(`/`ap` 等）组合，实现 “对指定范围的文本做大小写操作”。

### 例子场景

假设你有一行代码：

c

运行

```
int NAME = 123;
```

- 光标在 `NAME` 上：
    
    - `guiw`：`g`+`u`（小写）+`iw`（当前单词） → `name`
    - `gUiw`：`g`+`U`（大写）+`iw`（当前单词） → `NAME`（这里本身就是大写，效果不变）
    - `g~iw`：翻转大小写 → `name`（大写变小写）
    
- 光标在括号内：
    
    c
    
    运行
    
    ```
    printf("Hello World");
    ```
    
    `gu"` 会把引号内的内容全部转成小写 → `printf("hello world");`

## 2. `J`：连接两行

作用：把**当前行和下一行**合并成一行，中间用一个空格隔开。

### 例子场景

原来的文本：

plaintext

```
Hello
World
```

光标在 `Hello` 这一行，按 `J`：

plaintext

```
Hello World
```

### 进阶用法

- `3J`：合并当前行开始的 3 行
- 配合 `:set nojoinspaces` 可以让合并时不加空格

## 3. `<Ctrl-a>` / `<Ctrl-x>`：数字增减

作用：对光标下 / 光标后的数字进行 +1 /-1，非常适合改配置、写序号。

### 例子场景

假设你有：

c

运行

```
int a = 1;
int b = 2;
int c = 3;
```

- 光标在 `1` 上，按 `<Ctrl-a>` → `int a = 2;`
- 光标在 `2` 上，按 `<Ctrl-x>` → `int b = 1;`

### 进阶用法

- `5<Ctrl-a>`：数字 +5
- `3<Ctrl-x>`：数字 -3

---

## 4. `g<Ctrl-A>`：创建递增序列

作用：在多行数字上生成连续的递增序列，批量改序号神器！

### 例子场景

原来的文本：

c

运行

```
int arr[4] = {
    0,
    0,
    0,
    0
};
```

操作步骤：

1. 光标移到第一个 `0` 上，按 `Ctrl-v` 进入**块选择模式**
2. 用方向键向下选中所有 4 个 `0`
3. 输入 `g<Ctrl-A>`
4. 结果自动变成：
    
    c
    
    运行
    
    ```
    int arr[4] = {
        1,
        2,
        3,
        4
    };
    ```
    

---

## 5. `<` / `>`：缩进 / 反缩进

作用：给选中的文本整体向左 / 向右缩进一个 `shiftwidth`（默认是 4 个空格），写代码格式化超常用。

### 例子场景

原来的文本（缩进混乱）：

c

运行

```
if (true) {
printf("hello");
}
```

操作步骤：

1. 光标移到 `printf` 这一行，按 `V` 进入行选择模式
2. 输入 `>` → 向右缩进，变成：
    
    c
    
    运行
    
    ```
    if (true) {
        printf("hello");
    }
    ```
    
3. 如果缩进多了，按 `<` 可以缩回去

### 进阶用法

- `3>>`：当前行 + 下面 2 行，共 3 行一起右缩进
- `<<`：当前行左缩进
- `==`：自动缩进当前行（和语言语法对齐）




# `g<Ctrl-A>` 用法详细讲解
## 一、先搞懂它的核心作用

`g Ctrl+A` 是 **Vim 中配合块选择模式生成连续递增序列的命令**，专门用来批量给多行数字自动生成 `1,2,3,4...` 这样的序列，是改序号、写枚举、生成测试数据的神器。

它的核心逻辑：

- 以**选中的第一个数字为起点**，后面的每一行数字自动 `+1`，生成连续递增序列。

---

## 二、基础用法（你例子里的场景，再走一遍）

### 场景：给数组的 4 个 `0` 改成 `1,2,3,4`

原始文本：

c

运行

```
int arr[4] = {
    0,
    0,
    0,
    0
};
```

### 分步操作（关键细节都标出来）

1. **定位起点**：把光标移到第一个 `0` 上（注意：光标必须在数字的位置，不能在逗号或空格上）。
2. **进入块选择模式**：按 `Ctrl+v`，此时左下角会显示 `-- VISUAL BLOCK --`。
3. **垂直选中所有数字**：按 `↓` 键，向下移动，选中所有 4 个 `0`（注意：只选中数字本身，不要选中逗号或空格）。
4. **执行命令**：直接输入 `g`，然后按 `Ctrl+A`（注意：先按 `g`，再按 `Ctrl+A`，不是一起按）。
5. **结果自动生成**：
    
    c
    
    运行
    
    ```
    int arr[4] = {
        1,
        2,
        3,
        4
    };
    ```
    

---

## 三、进阶用法：自定义起点、步长、多列生成

### 1. 自定义起点：从 100 开始生成序列

原始文本：

plaintext

```
id: 0
id: 0
id: 0
```

操作：

- 把第一个 `0` 手动改成 `100`
- 按 `Ctrl+v` 选中所有 `0`
- 按 `g Ctrl+A`
- 结果：
    
    plaintext
    
    ```
    id: 100
    id: 101
    id: 102
    ```
    

### 2. 自定义步长：每次 +2（生成偶数序列）

原始文本：

plaintext

```
num: 1
num: 1
num: 1
```

操作：

- 选中所有 `1`
- 按 `2g Ctrl+A`（数字 `2` 代表步长）
- 结果：
    
    plaintext
    
    ```
    num: 1
    num: 3
    num: 5
    ```
    

### 3. 多列同时生成序列（超级实用！）

原始文本（想给两列都生成序号）：

plaintext

```
a: 0  b: 0
a: 0  b: 0
a: 0  b: 0
```

操作：

1. 按 `Ctrl+v` 选中第一列的 `0`，按 `g Ctrl+A` → 第一列变成 `1,2,3`
2. 再按 `Ctrl+v` 选中第二列的 `0`，按 `g Ctrl+A` → 第二列也变成 `1,2,3`
3. 最终结果：
    
    plaintext
    
    ```
    a: 1  b: 1
    a: 2  b: 2
    a: 3  b: 3
    ```

## 四、常见坑 & 避坑指南

1. **光标位置不对**
    
    ❌ 错误：光标在数字前面的空格 / 字母上，再按 `Ctrl+v` 选中
    
    ✅ 正确：光标必须**直接落在数字上**，再进入块选择模式
    
2. **选中范围不对**
    
    ❌ 错误：选中了数字后面的逗号、空格，导致命令执行异常
    
    ✅ 正确：块选择时，只选中数字本身，不要选中其他字符
    
3. **步长输入错误**
    
    ❌ 错误：先按 `Ctrl+A` 再按数字，顺序反了
    
    ✅ 正确：步长数字必须写在 `g` 前面，比如 `3g Ctrl+A` 代表每次 +3
    
4. **序列不连续**
    
    原因：Vim 默认按**选中的顺序**生成序列，只要是垂直选中，就会从上到下依次递增；如果是水平选中，会从左到右依次递增。

## 五、和普通 `Ctrl+A` 的区别（别搞混！）

表格

|命令|作用|适用场景|
|:--|:--|:--|
|`Ctrl+A`|给光标下的数字 +1（单次操作）|单个数字修改|
|`g Ctrl+A`|块选择模式下生成连续递增序列（批量操作）|多行 / 多列数字批量生成|

举个对比：

- 单个数字 `0`：按 `Ctrl+A` → `1`
- 三个 `0` 垂直选中：按 `g Ctrl+A` → `1,2,3`
