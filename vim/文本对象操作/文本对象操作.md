## 一、先搞懂两个核心前缀：`i` 和 `a`

- `i` = **inner**（只取内部，不含分隔符 / 空格）
- `a` = **around**（取整个对象，含分隔符 / 空格）

搭配 `d`（删除）、`c`（修改）、`v`（选中）就能直接用，比如 `diw`（删单词内部）、`ca(`（改整个括号）。

## 二、图里的两个核心例子拆解

### 例子 1：单词操作（对应 `iw` / `aw`）

文本：`Vim is a editor.`，光标在 `is` 上

表格

|命令|效果（选中范围）|实际操作|
|---|---|---|
|`iw`|只选中 `is` 这个单词本身|用 `diw` 会把 `is` 删掉，变成 `Vim a editor.`|
|`aw`|选中 `is`（单词 + 前后空格）|用 `daw` 会把 `is` 删掉，变成 `Vim a editor.`（前后空格也一起清掉了）|

---

### 例子 2：括号操作（对应 `i(` / `a(`）

文本：`(screen-based)`，光标在括号内

表格

|命令|效果（选中范围）|实际操作|
|---|---|---|
|`i(`|只选中括号里的 `screen-based`|用 `ci(` 会删掉括号里的内容，光标留在括号里进入插入模式，方便直接重写|
|`a(`|选中 `(screen-based)` 整个括号 + 内容|用 `da(` 会把整个括号和里面的内容一起删掉，文本直接消失|

## 三、再补 3 个高频场景，看完直接上手

### 场景 1：引号操作（处理字符串）

文本：`name = "LiHua"`，光标在双引号里

- `ci"`：删除引号里的 `LiHua`，光标留在引号里，直接输入新名字（比如 `ZhangWei`），比手动删效率高很多
- `da"`：把 `"LiHua"` 整个删掉，变成 `name =`

### 场景 2：代码块操作（处理大括号）

文本：

c

运行

```
if (flag) {
    printf("hello");
    return 0;
}
```

光标在 `{}` 里

- `di{`：只删除 `{}` 里的两行代码，`if (flag) {}` 保留
- `da{`：把 `{}` 和里面的代码一起删掉，变成 `if (flag) ;`

### 场景 3：句子 / 段落操作（处理文本）

文本：

plaintext

```
Vim is a screen-based editor.
It's super efficient.
```

光标在第一句

- `dis`：删除 `Vim is a screen-based editor.` 这句话本身
- `dip`：删除整个段落（这里就是两行文本）
