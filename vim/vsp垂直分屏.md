`:vsp` 是 Vim 里的**垂直分屏（vertical split）**命令，用来在当前窗口**右侧**新开一个垂直的编辑窗口。

---

#### 1. 基本用法

- **语法**：`:vsp [文件名]`
- **你的例子**：`:vsp hello.h`
    
    - 会在当前 `hello.c` 窗口的右侧，垂直打开一个新窗口来编辑 `hello.h`
    - 如果 `hello.h` 不存在，会新建这个文件
    

#### 2. 核心作用

- **多文件同时编辑**：比如你在写 `hello.c`，需要同时查看 / 编辑对应的头文件 `hello.h`，垂直分屏能让两个文件并排显示，方便对照和复制
- **代码结构清晰**：垂直分屏适合阅读长代码，避免水平分屏把代码挤得太窄

---

#### 3. 常用配套操作

表格

|操作|快捷键 / 命令|说明||
|---|---|---|---|
|**切换窗口**|`Ctrl + W` → `w`|在多个分屏之间循环切换光标||
|**关闭当前窗口**|`Ctrl + W` → `c` 或 `:q`|只关闭当前分屏，不影响其他窗口||
|**水平分屏**|`:sp [文件名]`|上下分屏（split 的缩写）||
|**调整窗口宽度**|`Ctrl + W` → `>` / `<`|增大 / 减小当前窗口宽度||
|**窗口最大化**|`Ctrl + W` → `|`|让当前窗口占满整个宽度|

---

#### 4. 常见场景示例

你现在的场景：

1. 打开 `hello.c`
2. 输入 `:vsp hello.h` → 右侧出现 `hello.h` 窗口
3. 用 `Ctrl+W w` 在两个文件间切换，一边写实现，一边写声明

---

#### 5. 补充说明

- `vsp` 是 `:vertical split` 的简写，完整写法也可以用 `:vs`（更短）
- 如果只想分屏不打开新文件，直接输入 `:vsp` 即可，会复制当前文件到新窗口
