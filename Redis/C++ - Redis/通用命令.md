# Redis 通用命令（C++ Redis++ 版）笔记

表格

|命令|作用说明|C++ 代码示例|
|:--|:--|:--|
|`SET`|添加 / 修改 String 类型键值对|`redis.set("key1", "Hello");`|
|`GET`|根据 key 获取 String 类型的 value|`auto val = redis.get("key1");`|
|`EXISTS`|判断一个或多个 key 是否存在|`redis.exists("key1");`<br><br>`redis.exists({"key1", "key2"});`|
|`DEL`|删除一个或多个 key|`redis.del("key1");`<br><br>`redis.del({"key1", "key2", "key3"});`|
|`KEYS`|按通配符模糊查询 key|`std::vector<std::string> keys;`<br><br>`redis.keys("*name*", std::back_inserter(keys));`|
|`EXPIRE`|为 key 设置过期时间（秒）|`redis.expire("mykey", std::chrono::seconds(10));`|
|`TTL`|查询 key 的剩余过期时间（秒）|`redis.ttl("mykey");`|
|`PTTL`|查询 key 的剩余过期时间（毫秒）|`redis.pttl("mykey");`|
|`TYPE`|判断 key 对应的数据类型|`redis.type("key1");`|
|`FLUSHDB`|清空当前数据库|`redis.flushdb();`|
|`MSET`|批量添加多个键值对|`std::unordered_map<std::string, std::string> kvs = {{"a", "1"}, {"b", "2"}};`<br><br>`redis.mset(kvs.begin(), kvs.end());`|
|`LPUSH`|向 List 类型 key 左侧插入元素|`redis.lpush("key2", "value");`|
|`SADD`|向 Set 类型 key 中添加元素|`redis.sadd("key3", "value");`|

## 补充说明

1. **`redis.flushdb()`**：用于清空当前数据库，在测试代码里用来避免之前的数据干扰结果。
2. **`std::chrono::seconds`**：Redis++ 里设置过期时间需要用 `std::chrono` 时间类型，比如 `seconds(10)` 代表 10 秒。
3. **`redis.keys()` 的使用**：除了 `std::insert_iterator`，更推荐用 `std::back_inserter`，写法更简洁：
    
    cpp
    
    运行
    
    ```
    std::vector<std::string> keys;
    redis.keys("*name*", std::back_inserter(keys));
    ```
