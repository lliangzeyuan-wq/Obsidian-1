Redis 是一个 key-value 数据库，key 一般为 String 类型，而 value 的类型多种多样，以下是常见的数据结构：

表格

| 数据结构            | 示例                        | 说明                         |
| :-------------- | :------------------------ | :------------------------- |
| **String**      | `hello world`             | 最基础的字符串类型，支持文本、数字、二进制数据存储  |
| **Hash**        | `{name: "Jack", age: 21}` | 键值对集合，适合存储对象数据             |
| **List**        | `[A -> B -> C -> C]`      | 有序字符串列表，允许重复元素，支持两端操作      |
| **Set**         | `{A, B, C}`               | 无序字符串集合，==不允许重复元素==        |
| **SortedSet**   | `{A: 1, B: 2, C: 3}`      | 有序集合，每个元素带一个分数，按分数排序       |
| **GEO**         | `{A: (120.3, 30.5)}`      | 地理位置存储，支持距离计算、附近查找         |
| **BitMap**      | `0110110101110101011`     | 位图，用位操作存储布尔数据，如签到统计        |
| **HyperLogLog** | `0110110101110101011`     | 用于基数统计，在极小内存下估算集合中不重复元素的数量 |
