### 🎯 针对 C++ WebServer 项目的学习截止点（精准版）

结合你新增的截图，我帮你明确《Linux 系统编程》学到**哪个具体章节就够了**，不用全看完，聚焦核心即可：

#### 🔴 必须看完的核心章节（WebServer 刚需）

1. **进程回收相关**
    
    - 孤儿 / 僵尸进程、wait/waitpid 回收子进程（含多子进程回收）
        
        ✅ 学到「wait 和 waitpid 总结」为止，掌握进程回收核心即可，错误解析可快速过。
    
2. **进程间通信（IPC）**
    
    - 管道（匿名管道基本用法、父子 / 兄弟进程通信）、命名管道 fifo、mmap 内存映射
        
        ✅ 学到「mmap 总结 / 父子进程 mmap 通信」为止，**文件 IPC、mmap 匿名映射区可跳过**（WebServer 初期用不到）。
    
3. **信号相关**
    
    - 信号概念 / 机制、信号集操作、signal/sigaction 信号捕捉
        
        ✅ 学到「sigaction 实现信号捕捉 + 信号捕捉特性」为止，内核实现简析可跳过（了解即可）。
    
4. **线程核心（重中之重）**
    
    - 线程概念、线程共享 / 非共享资源、创建线程（含多线程）
    - 互斥锁、条件变量（生产者消费者模型实现）、信号量基础
        
        ✅ 必须看完「条件变量实现生产者消费者代码实现 + signal 注意事项」，这是后续写**线程池**的核心基础；信号量部分学到基础概念即可。
    
5. **守护进程**
    
    ✅ 只需要看「守护进程创建」的基础流程（了解即可，WebServer 可后续优化时补）。
    

#### 🟡 可跳过 / 快速过的章节（非核心）

- 进程间通信里的「多个读写端操作管道缓冲区、文件用于进程间通信、mmap 匿名映射区」
- 信号部分的「内核实现信号捕捉简析」
- 线程部分的「三级映射、多消费者 while 循环细节」（后续遇到问题再回头看）

### 📌 总结：看到这些节点就停，转去学网络编程

当你看完：

`waitpid回收子进程 → 管道/mmap核心IPC → sigaction信号捕捉 → 线程创建 + 互斥锁/条件变量（生产者消费者）`

就可以停止《Linux 系统编程》的深入学习，立刻转去学《Linux 网络编程》的**Socket API + epoll + HTTP 协议**—— 这三部分才是 WebServer 的核心，系统编程学到这里的基础足够支撑你写第一个可运行的 WebServer 版本了。

如果后续写线程池、处理客户端超时连接时遇到问题，再回头补信号量、定时器相关的系统编程知识点即可。
